# Правила документации (Doc rules)

← [README](../../README.md) · [как читать](../HOW-TO-READ.md)

Как создавать и менять документы этого репозитория. Основа — **OpenSpec** (формат спек) и дополнения из **PDLC** ([openspec/config.yaml](../../openspec/config.yaml)): quality gate, уровни автономии R0–R5, правило «98/2», трассировка требование → задача → запуск.

| Документ | Для чего |
|---|---|
| [Критерии полноты спеки](spec-criteria.md) | Чек-лист: покрывает ли спека все сценарии |
| [Роли](roles.md) | Постановщик, автор критериев приёмки, автор R&D, проверяющий — кто что делает |
| [Типы документов](doc-types.md) | Правила для каждого типа: где лежит, разделы, кто пишет, что синхронизировать |
| [Процесс изменения](change-process.md) | Порядок шагов при любой правке документации + матрица синхронизации |
| [Промпты](prompts.md) | Готовые промпты для работы агента по ролям |

## Короткое правило

Любое изменение документации: **тип документа → его правила → связанные документы по матрице → проверки (`openspec validate --strict`, сборка сайта) → коммит**.
