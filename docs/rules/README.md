# Правила документации (Doc rules)

← [README](../../README.md) · [как читать](../HOW-TO-READ.md)

## Короткое правило

Любое изменение документации: **тип документа → [как с ним работать](doc-work.md) → источник факта → связанные документы по матрице → проверки (`openspec validate --strict`, сборка сайта) → коммит**.
