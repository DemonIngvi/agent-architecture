# Граф связности документов

← [Правила документации](README.md) · [процесс изменения](change-process.md)

Изменение в документе слева требует проверить документы справа по стрелкам. Источник графа — `html-view/docgraph.py`; на сайте он рисуется как схема (наведите на стрелку — что проверить).

<!-- docgraph -->

## Как пользоваться

1. Найдите на графе документ, который меняете.
2. Пройдите по всем исходящим стрелкам и проверьте документы на концах — что именно проверить, указано в таблице.
3. Повторяйте для каждого изменённого документа, пока не дойдёте до сводок (ROADMAP, TASKS, BACKLOG).
4. Проверки: `openspec validate --strict`, сборка сайта.

## Связи

| От | К | Что проверить |
|---|---|---|
| Запрос / ревью | User Stories | новая или изменённая история |
| Запрос / ревью | R&D | вопрос выбора |

| User Stories | traceability.md | колонка User Story |

| R&D | Данные сайта | RATIONALE, REFS, SUB |
| design.md | architecture.md | раздел и «Обоснование» |

| architecture.md | spec.md | границы и названия |

| spec.md | traceability.md | строка RTM |
