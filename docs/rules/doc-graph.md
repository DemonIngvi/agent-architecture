# Граф связности документов

← [Правила документации](README.md) · [процесс изменения](change-process.md)

Изменение в документе слева требует проверить документы справа по стрелкам. Источник графа — `html-view/docgraph.py`; на сайте он рисуется как схема (наведите на стрелку — что проверить).

<!-- docgraph -->

## Как пользоваться

Документы меняются **по одному**, в порядке стрелок ([путь изменения документа](agent-workflow.md)):

1. Найдите узел документа, который меняете: `./tools/doc next <файл>` выдаёт узел и документы на концах стрелок.
2. Правьте следующий документ только после того, как закончили текущий: его методология → правка → `./tools/doc check`.
3. У каждого следующего документа снова `next` — пока стрелки не приведут к документам, которые не изменились по смыслу.
4. Изменилась методология — первая стрелка ведёт к инструментам: сначала они, потом документы.
