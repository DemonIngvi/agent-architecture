# Методология сопровождающих документов

← [Правила документации](README.md) · [типы документов и вкладки](doc-types.md)

Как вести страницы, которые помогают ориентироваться: главная, таблица компонентов (README), справка, план документации, технологии, навигация сайта, индексы по компонентам.

## Назначение и читатель

Отвечают на вопросы **«где что лежит, с чего начать, на чём построено»**. Читатель — новый участник и владелец продукта.

## Основа

| Практика | Что берём |
|---|---|
| [Diátaxis](https://diataxis.fr) | разделять объяснение, справочник и инструкцию; справка — путеводитель, а не пересказ |
| [Технологический радар](https://www.thoughtworks.com/radar) (ThoughtWorks) | у технологии — кольцо Adopt / Trial / Assess / Hold и причина |
| Docs as code | страницы в git рядом с кодом; навигация и индексы генерируются |

## Из чего состоит

| Страница | Что в ней | Источник |
|---|---|---|
| Главная | карта платформы, обзор архитектуры (`architecture.md`), термины и коды, типы данных и интерфейсы | `html-view/home.md`, `architecture.md`, `docs/data-types.md` |
| README | вход в репозиторий на GitHub (не страница сайта) | `README.md` |
| Справка (раздел меню) | только общие страницы: правила, методологии, формат схем, персоны, промпты, журнал отклонений | навигация `build.py` |
| План документации | иерархия сайта, этапы работ над документацией | `docs/PLAN.md` |
| Технологии | технология, назначение, версия, лицензия, источник, кольцо радара, R&D | `docs/TECHNOLOGIES.md` |
| Бэклог | что отложено, почему, условие возврата | `docs/BACKLOG.md` |
| Навигация, индексы | меню сайта; спеки, задачи, R&D по компонентам | генерируются `build.py` |

## Как вести

1. Новая вкладка или раздел: строка в [правиле вкладок](doc-types.md#tabs) → место в меню (`nav_yaml`) и в верхней панели (`pagebar.py`) → иерархия в плане. Общих разделов «Архитектура» и «Требования» не заводим.
2. Новая технология: строка в TECHNOLOGIES с кольцом и ссылкой на R&D; версия — закреплённая; отказались — Hold с причиной.
3. «Справка» — только общее: ничего про данные наших компонентов.

## Чек-лист качества

- [ ] Каждая страница меню покрыта типом документа и методологией.
- [ ] В «Справке» нет страниц про наши компоненты.
- [ ] У технологии есть кольцо, версия, лицензия и R&D.

## Проверки в сборке

Ссылки и якоря без битых; версия LiteLLM в TECHNOLOGIES = схема в `datamodel.py`; R&D есть в реестре.
