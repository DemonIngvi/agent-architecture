## Иерархия

Структура сайта = меню слева; что в какой вкладке и чего в ней быть не должно — [вкладки и их наполнение](rules/doc-types.md#tabs).

```
Главная — карта платформы, обзор архитектуры, термины и коды, типы данных и интерфейсы
 ├─ Компонент ×11 ── Архитектура (страница компонента: блоки, почему так, конфигурация,
 │                   интеграции, контракты данных, хранилища), User Stories, Спеки, Задачи,
 │                   API, Техспека (как работает, развёртывание), R&D
 ├─ R&D ─────────── все исследования, по компонентам, последствия, решения OpenSpec
 ├─ План и задачи ─ Roadmap, сводная таблица, задачи, бэклог, технологии, этот план, ревью
 └─ Справка ─────── правила документации, методологии, формат схем, персоны, промпты, журнал
```

## Правила

- **Все связи — гиперссылки.** Каждый упомянутый компонент, спека, задача — ссылка на свой файл. В каждом файле — ссылка «вверх» (←) на родителя.
- **Страница компонента:** назначение, схема блоков, конфигурация, интеграции, контракты данных, хранилища, готовность, ссылки на спеки и задачи ([вкладки](rules/doc-types.md#tabs)).
- **Задачи — по INVEST** (Independent, Negotiable, Valuable, Estimable, Small, Testable): зачем, что сделать, критерий приёмки, статус.
- **Статусы:** ✅ сделано · ⚠️ частично · ⬜ не начато. Уже сделанное тоже показываем.
- **Схемы** — ASCII в согласованном формате ([FORMAT.md](../FORMAT.md)).
- **Описание и задачи разделены:** действующее описание — `openspec/specs/`, доработки — `openspec/changes/`.
