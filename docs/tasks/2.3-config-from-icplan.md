## Зачем

Пользователь настраивает агента в UI ICPlan; Harness должен брать модель, инструкцию и тулы оттуда, а недостающее (лимиты, approve) — из YAML до появления Platform module.

## Что сделать

- Чтение определения агента у Platform module: `GET /platform/runs/:runId/agent` → `{version, definition, settings}` (I4, [D23](../../openspec/changes/define-agent-platform/design.md), [R&D](../rnd/runner-agent-definition.md))
- Минимальный Platform module: этот эндпоинт и сервисный токен Runner; версия запуска — в `agent_run.agent_version` при первом вызове
- Слияние с YAML: что из ICPlan, что из YAML
- Перенос алиаса модели на LiteLLM
- Тулы, навыки, MCP-серверы агента и критерии приёмки задачи (L3) из ICPlan в `RunBundle`

## Приёмка

- [ ] Изменить `agent.model` или инструкцию агента в ICPlan во время запуска → активный запуск на старой, следующий — на новой (R-REG-07 «Изменение настройки»)
- [ ] Сменить модель агента и вернуть прежнюю → новые запуски на новой, затем на прежней; модель, не настроенная в LiteLLM, отклонена (R-REG-06 «Замена модели», «Модель без доступа», «Откат модели»)
- [ ] Сохранить агента без `agent.model` → отказ, ошибка называет `agent.model` (R-REG-07 «Нет обязательного поля», R-REG-02 «Обязательное поле отсутствует»)
- [ ] Выключить агента (`agent.enabled = false`) → в списке «выключен», делегирование отклонено с причиной (R-ICP-08 «Агент выключен», R-REG-02 «Выключение агента»)
- [ ] Остановить Runner дольше порога → агенты платформы «не в сети»; запустить → «в сети» (R-ICP-08)
- [ ] БД ICPlan недоступна → определения не читаются, запуски не стартуют (R-REG-08 «S1 недоступно», R-REG-10 «БД ICPlan недоступна»)
- [ ] Пользователь без права меняет определение → 403, данные не меняются (R-REG-09 «Права по I20»)
- [ ] Лимиты из YAML дополнений попадают в `RunBundle.params`
- [ ] Запуск, ждущий слота, после правки агента стартует с новой версией; повторная выдача запуска получает ту же версию (`agent_run.agent_version`, D23)
- [ ] Запрос определения по запуску не в `pending` или агента не `external` → 404; версии нет → 409 (D23)

**Как прокликать:** ICPlan: поменять инструкцию агента → делегировать → ответ по новой инструкции
