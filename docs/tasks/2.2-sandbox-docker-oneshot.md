## Зачем

Изоляция запусков с первого дня интеграции; тёплый пул — оптимизация позже (4.1).

## Что сделать

- Образ Harness
- `SandboxProvider` (Docker): create / exec / destroy
- Эфемерный `/workspace`
- Лимиты CPU/RAM из профиля

## Приёмка

- [ ] После запуска контейнера нет
- [ ] Два параллельных запуска не видят файлы друг друга
- [ ] Лимит RAM применяется

**Как прокликать:** Делегировать 2 задачи подряд → `docker ps` пуст после завершения, ответы в задачах
