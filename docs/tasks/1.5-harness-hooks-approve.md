## Зачем

Approve опасных действий — обязательное требование; механизм паузы и возобновления нужен и для вопросов пользователю. Проще заложить в ядро сейчас, чем встраивать потом.

## Что сделать

- Hooks before/after llm и tool, on_stop — интерфейс плагинов
- Пауза (`interrupt`) перед тулом, помеченным как требующий подтверждения
- Checkpointer: состояние сохраняется, возобновление с того же шага после ответа или падения процесса
- Ответ на паузу: approve / reject / ответ на вопрос

## Приёмка

- [ ] Hook отклоняет тул → агент получает отказ
- [ ] Опасный тул → запуск в статусе «ждёт подтверждения»
- [ ] Approve → продолжение без повтора прошлых шагов
- [ ] Убитый процесс → новый продолжает с checkpoint

**Как прокликать:** UI 1.7: агент остановился, кнопка «одобрить» → продолжил
