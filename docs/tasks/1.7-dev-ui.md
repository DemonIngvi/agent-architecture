## Зачем

Нужно видеть работу агента кликами до интеграции с ICPlan: шаги, вызовы тулов, паузы на approve.

## Что сделать

- Выбор и проверка готового UI: Agent Chat UI (open-source) или LangGraph Studio
- Запуск harness как локального LangGraph-сервера
- Выбор агента (YAML), отправка задачи, просмотр шагов, кнопки approve/reject

## Приёмка

- [ ] В браузере: выбрать агента → задача → ответ
- [ ] Видны шаги и вызовы тулов
- [ ] Пауза на approve управляется из UI

**Как прокликать:** `localhost:<порт>`: весь сценарий этапа 1 проходится мышкой

## Что проработать

Список открытых вопросов — пройдём отдельно и заполним упущения.

- [ ] Проверить актуальное состояние Agent Chat UI и LangGraph Studio (лицензии, нужна ли учётка LangSmith)

- [ ] Как выбирать агента в UI: по графу на агента или параметром
