## Зачем

Процесс «перевёл в статус → агент взял» — ключевая автоматизация, которой сейчас нет.

## Что сделать

- Поле агента-делегата у статуса, запуск при входе задачи
- Защита от дублей
- UI в настройках статусов

## Приёмка

- [ ] Перевод задачи в статус создаёт один запуск агента

**Как прокликать:** Перетащить задачу в статус → агент взял её и ответил
