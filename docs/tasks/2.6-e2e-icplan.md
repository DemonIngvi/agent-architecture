## Зачем

Фиксирует, что этап 2 работает целиком и не ломается при следующих доработках.

## Что сделать

- Автотест сценария: задача → делегат → Runner → контейнер → Harness → MCP → M3 → итог
- Смена модели агента без перезапуска
- Автотесты отказов по R-ICP-13, R-RUN-08, R-RUN-14
- Инструкция ручной проверки

## Приёмка

- [ ] Автотест проходит на локальном стеке
- [ ] Ручной сценарий по инструкции проходит
- [ ] Итог не по формату определения → запуск `gate_failed`; остановка по лимиту → в задаче частичный итог «не завершено» (R-RUN-08)
- [ ] Runner не в сети → агенты «не в сети», запуски ждут; несовместимая версия протокола → Runner не берёт запуски (R-ICP-13)
- [ ] RustFS недоступно → итог опубликован без вложений, загрузка повторяется (R-ICP-13)
- [ ] ICPlan недоступен → опрос с backoff, активный запуск продолжается, события доставлены после восстановления (R-RUN-14)
- [ ] Platform module недоступен → новый запуск не стартует; Docker недоступен → запуск остаётся `queued` (R-RUN-14)
- [ ] Runner упал → запуск вернулся в очередь, слот освобождён (R-RUN-14)

**Как прокликать:** Пошаговая инструкция в документе: что нажать в ICPlan и что увидеть
