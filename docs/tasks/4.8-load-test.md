## Зачем

Профиль нагрузки — гипотеза; без замера нельзя выпускать в продуктив и настраивать лимиты.

## Что сделать

- Сценарии k6: UI ICPlan, опрос Runner, события, вызовы LiteLLM (mock)
- Замер `kubectl top`, p95, RPS, ошибки
- Сравнение с профилем, обновление R&D и лимитов

## Приёмка

- [ ] Отчёт: p95 API < 300 мс при 20 RPS
- [ ] Потребление узла записано
- [ ] Профиль в R&D обновлён

**Как прокликать:** запустить k6 → отчёт с графиками и сравнением с профилем
