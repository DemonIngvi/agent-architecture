## Зачем

Агент должен читать задачу, писать комментарии и менять статус — иначе процесс между этапами не работает.

## Что сделать

- Подключение MCP ICPlan в определении агента
- Ключ агента для MCP без попадания в контекст
- Allowlist тулов (issue.*, docs.*)

## Приёмка

- [ ] Агент читает задачу и пишет комментарий
- [ ] Агент переводит задачу в другой статус

**Как прокликать:** Делегировать задачу → агент оставил комментарий и сменил статус

## Декомпозиция

Подзадачи по 2–8 часов; каждая проверяема сама по себе.

| # | Подзадача | Человек, ч | Готово, когда |
|---|---|---|---|
| 2.4.1 | Включить MCP проекта, ключ агента | 2 | MCP отвечает агенту |
| 2.4.2 | MCP-клиент Harness: ключ вне контекста модели | 4 | ключа нет в промпте и событиях |
| 2.4.3 | Минимальный allowlist тулов ICPlan | 2 | список в определении агента |
| 2.4.4 | Тест: комментарий и смена статуса | 3 | агент меняет статус задачи |
| | **Итого** | **11 ч ≈ 1.4 дн** | |
