## Зачем

Расширение автоматизации (типы задач, произвольные условия) и видимость стоимости задачи.

## Что сделать

- Агент-делегат типа задачи
- Эффект Действия «делегировать агенту» (T-04)
- Затраты (токены, $) в задаче из LiteLLM

## Приёмка

- [ ] Задача типа X уходит агенту
- [ ] Действие по метке запускает агента
- [ ] В задаче видны токены и $

**Как прокликать:** Создать задачу типа X; поставить метку; открыть затраты задачи

## Декомпозиция

Подзадачи по 2–8 часов; каждая проверяема сама по себе.

| # | Подзадача | Человек, ч | Готово, когда |
|---|---|---|---|
| 3.5.1 | Агент-делегат типа задачи: поле, делегирование, UI | 10 | задача типа уходит агенту |
| 3.5.2 | Эффект Действия `delegate_agent` + UI | 10 | действие по метке запускает агента |
