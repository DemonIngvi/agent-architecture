## Зачем

Расширение автоматизации (произвольные условия Действий) и видимость стоимости задачи. Процесс типа задачи — в [3.1](3.1-icplan-process-step-agent.md).

## Что сделать

- Эффект Действия «делегировать агенту» (T-04)
- Затраты (токены, $) в задаче из LiteLLM

## Приёмка

- [ ] Поставить метку, по которой Действие делегирует агенту → делегат — агент Действия, запуск в очереди; без метки — не срабатывает (R-AP-03 «Действие по метке», «Условие не выполнено»)
- [ ] Действие ссылается на выключенного агента → запуска нет, ошибка в истории задачи (R-AP-03 «Агент отключён»)
- [ ] Открыть задачу с тремя запусками → сумма токенов и $ по задаче (R-OBS-05 «Затраты задачи», R-LLM-02 «Подсчёт по запуску»)
- [ ] У модели нет цены → токены учтены, стоимость «неизвестна» (R-OBS-05 «Нет данных о цене»)
- [ ] Вызов модели без `run_id` → отклонён; вызов с `run_id` и задачей → затраты привязаны к запуску и задаче (R-LLM-03 «Вызов без метаданных», «Вызов с метаданными»)
- [ ] Ответ стримом и ошибка провайдера → токены стрима учтены по завершении, неуспешный вызов учтён отдельно (R-LLM-02 «Стрим», «Ошибка провайдера»)

**Как прокликать:** Поставить метку → агент Действия взял задачу; открыть затраты задачи
