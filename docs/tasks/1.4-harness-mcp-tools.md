## Зачем

Без тулов агент только отвечает текстом. Allowlist из конфига — первая граница безопасности (до OPA).

## Что сделать

- Подключение MCP-серверов из определения агента (адаптер MCP → тулы LangGraph)
- Allowlist: агенту видны только перечисленные тулы
- Таймауты и ошибки тулов возвращаются агенту как результат, цикл продолжается
- Тестовый MCP-сервер (echo / файлы) для проверок
- Описание рабочего пространства в контексте, тулы только внутри `/workspace`, артефакты в `RunResult`

## Приёмка

- [ ] Агент вызывает тул MCP и получает результат
- [ ] Тул вне allowlist не виден и не вызывается
- [ ] Таймаут тула → ошибка в результате, запуск не падает
- [ ] Новый MCP-сервер добавлен агенту → тулы доступны со следующего запуска; сервер не отвечает при регистрации → пометка «недоступен», тулы не выдаются; тот же адрес повторно → отклонено как дубликат (R-MCP-01)
- [ ] Тул ответил вовремя → результат агенту; ответ больше лимита → обрезан с пометкой, контекст не переполняется (R-MCP-03)
- [ ] MCP-сервер недоступен → ошибка тула агенту; секрет не задан → тулы сервера недоступны, предупреждение; сервер изменил набор тулов → новые тулы не видны без allowlist (R-MCP-10)
- [ ] MCP-сервер недоступен → ошибка тула возвращается агенту, цикл продолжается (R-HRN-13)
- [ ] Запуск с манифестом из двух источников → агент видит пути и права; файловый тул с путём вне `/workspace` → отклонён; итог → `RunResult` со списком артефактов; изменён lock-файл и вызван `install_dependencies` → шаг подготовки повторён, `/workspace/.deps` обновлён (R-HRN-17)
- [ ] Новые зависимости → Runner повторяет шаг подготовки (D19), `/workspace/.deps` обновлён, цикл продолжается (R-HRN-17)
- [ ] Описание в контексте → агент видит пути и права в контексте (R-HRN-17)
- [ ] Вызов в обход Harness → соединение недоступно: MCP-серверы доступны только через MCP-прокси Runner, вызов вне allowlist прокси отклоняет (R-MCP-02)
- [ ] Недоступный MCP → агент получает ошибку тула и продолжает цикл (R-MCP-03)
- [ ] Успешный вызов → результат возвращается агенту (R-MCP-03)
- [ ] Выше максимума → значение отклонено, ошибка называет `timeout_s` и границы 5–300 (R-MCP-07)
- [ ] Значение по умолчанию → применяется значение по умолчанию: itsaplan-core (R-MCP-07)
- [ ] Нет обязательного поля → сохранение отклонено, ошибка называет `auth.secret_ref` (R-MCP-07)
- [ ] S1 недоступно → тулы ICPlan возвращают ошибку агенту с типом «недоступно»; агент не повторяет записи сам (R-MCP-08)
- [ ] Запись в своё хранилище → запись попадает в S1 (PostgreSQL 17 (CloudNativePG), БД `itsaplan`) (R-MCP-08)
- [ ] Аутентификация I17 → вызов не повторяется, событие с причиной (R-MCP-09)
- [ ] Неидемпотентный вызов I9 → автоматического повтора нет, решение принимает вызывающий (R-MCP-09)
- [ ] Таймаут I9 → вызов прерывается; повтор: чтение — 2 раза; запись — нет (R-MCP-09)
- [ ] Новый тул на сервере → агенту он не виден (R-MCP-02)

**Как прокликать:** автотест сценария на mock-LLM (CLI-запуск, вывод шагов): в шагах виден вызов тула и его ответ
