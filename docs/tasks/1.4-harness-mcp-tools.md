## Зачем

Без тулов агент только отвечает текстом. Allowlist из конфига — первая граница безопасности (до OPA).

## Что сделать

- Подключение MCP-серверов из определения агента (адаптер MCP → тулы LangGraph)
- Allowlist: агенту видны только перечисленные тулы
- Таймауты и ошибки тулов возвращаются агенту как результат, цикл продолжается
- Тестовый MCP-сервер (echo / файлы) для проверок

## Приёмка

- [ ] Агент вызывает тул MCP и получает результат
- [ ] Тул вне allowlist не виден и не вызывается
- [ ] Таймаут тула → ошибка в результате, запуск не падает

**Как прокликать:** UI 1.7: в шагах виден вызов тула и его ответ

Подзадачи по 2–8 часов; каждая проверяема сама по себе.

## Что проработать

Список открытых вопросов — пройдём отдельно и заполним упущения.

- [ ] MCP-клиент: `langchain[mcp]` (`langchain.mcp`) — официальная замена архивного `langchain-mcp-adapters`; проверить по [гайду миграции](https://docs.langchain.com/oss/python/migrate/langchain-mcp-adapters)
- [ ] Транспорт MCP: http/sse/stdio — что поддерживаем в MVP
- [ ] Авторизация к MCP: где берётся токен, как не попасть в контекст агента
- [ ] Нативные тулы Harness (R4) — какие нужны в MVP (запись M3?)
- [ ] Ограничение размера ответа тула (обрезка, чтобы не взорвать контекст)
