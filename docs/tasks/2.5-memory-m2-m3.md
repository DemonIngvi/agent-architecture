## Зачем

Агент следующего этапа должен продолжать работу, а не начинать с нуля. M3 — самый дешёвый способ дать это.

## Что сделать

- Хранилище M3 (состояние задачи)
- Тул записи M3 для агента
- Подача M3 и итогов последних N запусков (M2) в контекст

## Приёмка

- [ ] Агент записал M3 → следующий агент видит его в контексте
- [ ] Итоги прошлых запусков в контексте

**Как прокликать:** Два агента по одной задаче: второй ссылается на то, что сделал первый
