## Зачем

Правила безопасности в одном месте, проверяемые и отключаемые конфигом.

## Что сделать

- Конфиг `guardrails.gN.enabled`, режим отказа
- OPA: G1 в Runner, G2 в hooks Harness
- Rego в git + `opa test`
- Аудит решений

## Приёмка

- [ ] Выключенная точка не проверяется
- [ ] Тул вне политики отклонён с причиной
- [ ] OPA недоступен → deny

**Как прокликать:** Включить G2, вызвать запрещённый тул → отказ в таймлайне

## Декомпозиция

Подзадачи по 2–8 часов; каждая проверяема сама по себе.

| # | Подзадача | Человек, ч | Готово, когда |
|---|---|---|---|
| 4.3.1 | Конфиг `guardrails.gN.enabled`, режим отказа | 4 | выключенная точка не проверяется |
