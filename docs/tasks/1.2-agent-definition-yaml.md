## Зачем

Формат YAML — контракт между ICPlan, Harness и экспортом/импортом. Зафиксировав его первым, мы делаем Harness сейчас, а в ICPlan потом переносим тот же формат без переделок.

## Что сделать

- Схема (JSON Schema) по модели [`AgentDefinition`](../api/icplan.md) (`agent/v1`): поля Registry — `apiVersion`, `id`, `version`, `model` (алиас LiteLLM), `instructions`, `skills`, `mcp` (`{server, tools[]}` — allowlist тулов); поля Platform module (R-REG-02, хранятся в `AgentSettings`, в YAML — при экспорте и импорте) — `limits`, `approval`, `memory`, `sandbox`
- Валидатор схемы + проверка ссылок (MCP, скиллы существуют)
- 2 примера: агент-аналитик (без тулов записи), агент с MCP и approve на опасном туле
- Документ формата с примерами

## Приёмка

- [ ] Два примера прогнать через валидатор → оба проходят (R-REG-05 «Все ссылки верны»)
- [ ] Определение без `model` → отказ, ошибка называет поле (R-REG-02 «Обязательное поле отсутствует»)
- [ ] Ссылка на несуществующий навык → отказ с указанием битой ссылки (R-REG-05 «Битая ссылка»)
- [ ] Ресурс с неподдерживаемым типом или повторным `id` в каталоге примеров → отказ, у типа — перечень допустимых (R-REG-01 «Неизвестный тип», «Дубликат»)
- [ ] `model.temperature` > 1.0 или `limits.max_tokens` выше потолка `budget.per_run_tokens` → отказ с именем параметра и границами (R-HRN-10 «Выше максимума», «Граница от другого параметра»)
- [ ] Без `model.temperature` → в итоговых параметрах 0.2 (R-HRN-10 «Значение по умолчанию»)
- [ ] Поля, которые Harness читает из `RunBundle.agent`, есть в схеме

**Как прокликать:** Запуск валидатора на примерах: ✅ на корректных, ❌ с текстом ошибки на испорченных

Подзадачи по 2–8 часов; каждая проверяема сама по себе.

| # | Подзадача | Человек, ч | Готово, когда |

| 1.2.2 | Валидатор: схема + проверка ссылок (MCP, навыки, профили) | 4 | битая ссылка → понятная ошибка |
| 1.2.3 | Два примера: аналитик и агент с approve | 2 | примеры проходят валидацию |
| 1.2.4 | Документ формата и соответствие полям ICPlan | 2 | таблица полей: ICPlan / наше |
