## Зачем

Перенести настройки из YAML в ICPlan: бюджеты, профили, данные guardrails, версии — с UI.

## Что сделать

- Схема БД модуля
- API
- Экраны в UI ICPlan по [D24](../../openspec/changes/define-agent-platform/design.md) ([R&D](../rnd/platform-module-screens.md)): агент — раздел «Платформа» в карточке агента; проект — Проект → ИИ-команда → «Платформа»; экземпляр — God mode → «Платформа» через `@/cloud`; права — ресурс `ai_agents` форка, God mode — владелец экземпляра
- Карточка внешнего агента: поля Registry (модель-алиас, навыки, тулы, MCP; R-REG-02, D23)
- PR в upstream: точка расширения разделов карточки и проекта через `@/cloud`; до принятия — правка `TeamAiAgentFields.tsx`, `settingsSections.ts` и сообщений
- Версии определения агента, экспорт/импорт YAML
- Руководство проекта для агентов

## Приёмка

- [ ] Настройки агента меняются в UI и применяются к следующему запуску
- [ ] Экспорт → импорт даёт тот же агент
- [ ] Настройки агента — в карточке, проекта — в разделе «ИИ-команда», экземпляра — в God mode; без права `ai_agents` — только чтение, God mode — только владелец экземпляра (D24)

**Как прокликать:** ICPlan: экран настроек агента (бюджет, профиль) → запуск учитывает
