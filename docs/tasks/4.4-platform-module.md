## Зачем

Перенести настройки из YAML в ICPlan: бюджеты, профили, данные guardrails, версии — с UI.

## Что сделать

- Схема БД модуля
- API
- Экраны в UI ICPlan
- Версии определения агента, экспорт/импорт YAML

## Приёмка

- [ ] Настройки агента меняются в UI и применяются к следующему запуску
- [ ] Экспорт → импорт даёт тот же агент

**Как прокликать:** ICPlan: экран настроек агента (бюджет, профиль) → запуск учитывает
