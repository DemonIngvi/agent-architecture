## Зачем

Перенести настройки из YAML в ICPlan: бюджеты, профили, данные guardrails, версии — с UI.

## Что сделать

- Схема БД модуля
- API
- Экраны в UI ICPlan
- Версии определения агента, экспорт/импорт YAML

## Приёмка

- [ ] Настройки агента меняются в UI и применяются к следующему запуску
- [ ] Экспорт → импорт даёт тот же агент

**Как прокликать:** ICPlan: экран настроек агента (бюджет, профиль) → запуск учитывает

## INVEST

| | |
|---|---|
| **I** Independent | Поверх 2.3 |
| **N** Negotiable | Набор экранов |
| **V** Valuable | Всё в одном UI |
| **E** Estimable | 8–12 дней |
| **S** Small | Нет — делить на подзадачи при планировании |
| **T** Testable | Тесты ICPlan |

## Что проработать

Список открытых вопросов — пройдём отдельно и заполним упущения.

- [ ] Разбить на подзадачи (схема, API, каждый экран)
- [ ] Стратегия слияния с upstream ICPlan
- [ ] Права на настройки
