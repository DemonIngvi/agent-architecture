## Зачем

Следующий агент должен получать итог предыдущего, а пользователь — понимать, почему агент начал работу.

## Что сделать

- Передача по контракту шага (D20): M3, ссылки на артефакты, предложенные критерии; ссылка на итог
- Запись «агент взял задачу по правилу…» в истории

## Приёмка

- [ ] Цепочка из 2 статусов и 2 агентов проходит сама
- [ ] В истории видно правило подхвата

**Как прокликать:** Задача проходит 2 статуса без участия человека

## Декомпозиция

Подзадачи по 2–8 часов; каждая проверяема сама по себе.

| # | Подзадача | Человек, ч | Готово, когда |
|---|---|---|---|
| 3.2.1 | Ссылка на итог предыдущего запуска в задании | 6 | промпт содержит ссылку |
| 3.2.2 | Запись «агент взял задачу по правилу …» в истории | 4 | событие в истории |
| 3.2.3 | Отображение в UI истории | 3 | видно правило |
| 3.2.4 | Тест цепочки из 2 статусов и 2 агентов | 4 | цепочка проходит сама |
| 3.2.5 | Передача по контракту шага (D20): M3 → задание; `criteriaNext` → чек-лист с пометкой автора; подтверждение по `criteria_approval` | 4 | критерий аналитика виден разработчику с пометкой |
