← [README](../../README.md) · [architecture.md](../../architecture.md) · [design.md (решения D1–D14)](../../openspec/changes/define-agent-platform/design.md)

Исследования, на которых основаны решения. Проводятся по [методологии R&D v3](../rules/rnd-methodology.md): цепочка «потребность → ключевые функции → ценность → перенос → выбор», ворота между этапами, критерии как следствие цепочки, первая страница — ответ и основания за 3 минуты ([почему так](rnd-methodology-choice.md)). Колонка «Методология»: **v3** — оформлено полностью; **v1 + альтернативы** — есть альтернативы и сравнение по фактам, нужно перевести на v3 (потребности, функции, ценность, перенос, ворота, первая страница).
