## Профиль технологий

Данные GitHub API на 10.10.2026.

| Технология | Лицензия | ★ | Последний релиз | Активность | Распространённость, поток, токены, сеть |
|---|---|---|---|---|---|

## Последствия

**Плюсы**

- Таймлайн без новых сервисов

**Минусы и риски**

- Нет evals и анализа промптов до подключения Langfuse
