## Контекст

Агент следующего этапа должен продолжать работу, а не начинать заново; контекст не должен раздуваться всей историей.

## Последствия

**Плюсы**

- M3 даёт преемственность этапов почти бесплатно
- В контекст попадает нужное — меньше токенов

**Минусы и риски**

- Нужно дисциплинированно писать M3 (инструкция агента + тул)
