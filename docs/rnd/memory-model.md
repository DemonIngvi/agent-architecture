## Сопоставление

| M (проект AI-агент) | Что | Где | Есть в ICPlan | L (наш первый вариант) |
|---|---|---|---|---|
| M0 рабочая | контекст запуска | процесс | ✅ | L1 |
| M1 сессионная | тред | Postgres | ✅ | L2 частично |
| M2 эпизодическая | запуски и итоги | `agent_run` | ✅ | L2/L3 размыто |
| M3 задачная | сделано / дальше / блокеры | — | ❌ | L2 без структуры |
| M4 семантическая | факты, поиск по смыслу | pgvector | ❌ | L3/L4 |
| M5 процедурная | инструкция, навыки | БД | ✅ | не считали памятью |
| M6 организационная | документы проекта | документы | ✅ | L4 частично |

## Почему M0–M6

- Уровни делят память **по виду знания**, у каждого понятно, кто, когда и куда пишет. L-уровни делили **по области видимости** и смешивали виды.
- Деление на рабочую, эпизодическую, семантическую и процедурную память — общепринятое в исследованиях агентов (CoALA).
- 5 из 7 уровней уже есть в ICPlan.

## Решение

M0–M6; область видимости — атрибут записи. Порядок: M3 → M2 в контекст → M4 с RAG.
