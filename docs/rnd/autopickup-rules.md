## Контекст

Сейчас агент запускается только при ручной смене делегата или упоминании; автоназначение на статус ставит исполнителя и запуск не создаёт. Процесс «задача пришла в этап → агент взял» нужен без кода, настраиваемым пользователем.

## Обязательные требования (knock-out)

- Процесс настраивает пользователь в ICPlan без кода

- ✗ **Внешний оркестратор (Temporal / n8n)** — процесс описывается вне ICPlan, кодом или в отдельном UI

## Последствия

**Плюсы**

- Процесс виден прямо на доске и настраивается мышкой
- Опирается на существующий механизм делегирования

**Минусы и риски**

- Один агент на статус
- Порядок этапов задаётся статусами, параллельных веток нет
