## Контекст

Нужна одна точка выхода к моделям: смена модели без кода, учёт и лимиты по агенту, работа без ключей при разработке.

## Последствия

**Плюсы**

- Смена модели без изменения агентов
- Учёт и бюджеты по агенту и задаче
- Mock для разработки

**Минусы и риски**

- Лишний хоп и единая точка отказа — реплики
- Часть функций — enterprise-лицензия
