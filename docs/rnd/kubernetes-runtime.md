## Последствия

**Плюсы**

- Тот же движок локально (k3d) и на сервере (k3s)
- Готовые чарты из проекта AI-агент

**Минусы и риски**

- Один узел — нет отказоустойчивости control plane
- Две среды (compose и k3s) нужно держать согласованными
