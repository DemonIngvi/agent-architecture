## Контекст

Настройки агентов меняют люди в UI и иногда нужно ревьюить и переносить между окружениями.

## Альтернативы

| Вариант | Что это и как решает вопрос | Подходит, если |
|---|---|---|
| **БД ICPlan + экспорт / импорт YAML** | настройки агентов в БД ICPlan (S1, S2), перенос между средами — YAML | настройки меняют администраторы в интерфейсе |
| **Отдельный Platform API** | собственный сервис настроек со своей БД | настройки нужны многим системам кроме ICPlan |
| **Git (Config Repo)** | настройки агентов — файлы в git, применяются из репозитория | настройки меняют разработчики через PR |

## Сравнение по существу вопроса

Критерии выведены из вопроса; в клетках — факты. Баллы матрицы ниже следуют из этих фактов.

| Критерий (почему важен) | БД ICPlan + экспорт / импорт YAML | Отдельный Platform API | Git (Config Repo) |
|---|---|---|---|
| Кто меняет — администратор без git | в интерфейсе ICPlan | в отдельном интерфейсе | через PR в git |
| Версии и откат | версии определения в БД, YAML | свои версии | история git |
| Новые сервисы | нет | сервис + БД | конвейер применения |
| Источник правды при расхождении | S2 (D9) | сервис | git |

**Почему выбрано:** администратор меняет настройки там, где работает, версии есть, лишних сервисов нет; Rego остаётся в git (правила — код).
