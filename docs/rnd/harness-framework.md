## Контекст

Нужны: пауза на подтверждение человека и продолжение с того же шага, восстановление после падения, стрим шагов для таймлайна, любая модель через LiteLLM.

## Альтернативы

| Вариант | Что это и как решает вопрос | Подходит, если |
|---|---|---|
| **LangGraph** | граф агентского цикла с checkpoint, прерыванием на подтверждение и стримом шагов | нужны пауза на approve, восстановление и наблюдаемость шагов |
| **OpenAI Agents SDK** | лёгкий цикл агента с тулами и handoff | один провайдер OpenAI, простые агенты |
| **Claude Agent SDK** | агент Claude Code как библиотека | агент работает как кодинг-агент Claude |
| **Свой цикл** | цикл вызова модели и тулов в своём коде | нужен полный контроль и мало функций |
| **Hermes Agent** | готовый агент (Nous Research, MIT): память, навыки, канбан агентов, шлюзы мессенджеров | нужен готовый автономный агент, а не библиотека цикла |

## Сравнение по существу вопроса

Критерии выведены из вопроса; в клетках — факты. Баллы матрицы ниже следуют из этих фактов.

| Критерий (почему важен) | LangGraph | OpenAI Agents SDK | Claude Agent SDK | Свой цикл | Hermes Agent |
|---|---|---|---|---|---|
| Пауза на подтверждение и возобновление — G2 | `interrupt` + checkpointer | нет готового checkpoint | свои механизмы сессии | писать самим | не подтверждено — нужен прототип |
| Любая модель через LiteLLM | да (OpenAI-совместимый клиент) | да, через совместимый API | модели Claude | да | несколько провайдеров; через LiteLLM — не подтверждено |
| Стрим шагов для таймлайна | события графа | трассировка SDK | поток сообщений | писать самим | не подтверждено |
| Лицензия и зрелость | MIT, 1.2.14 | MIT | коммерческие условия Anthropic | — | MIT, 252 523★, активен |

**Почему выбрано:** из коробки дают пауза с checkpoint и любая модель; закрыт своим интерфейсом harness, чтобы менять фреймворк. Hermes Agent — готовый агент, а не библиотека: встраивание в Runner, G2 и checkpoint не подтверждено — прототип до решения о замене.

## Последствия

**Плюсы**

- Approve, восстановление, стрим — без своего кода
- Возобновление с checkpoint не повторяет шаги — меньше токенов

**Минусы и риски**

- Частые изменения API LangChain — фиксируем версию и держим за своим интерфейсом
