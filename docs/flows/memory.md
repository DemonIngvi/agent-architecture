# Потоки: Memory

← [Все потоки](README.md)

## Потоки

| # | Поток | Уровень | От → к | Когда |
|---|---|---|---|---|
| 1 | Переписка треда | M1 | ICPlan → БД | каждое сообщение, автоматически |
| 2 | Итог запуска | M2 | Runner → БД (`agent_run`) | конец запуска, автоматически |
| 3 | Состояние задачи | M3 | агент → тул памяти → БД | когда агент продвинулся |
| 4 | Контекст нового запуска | M2, M3, M5, M6 | Memory → Harness | старт запуска |
| 5 | Факты для поиска по смыслу | M4 | агент → pgvector | после MVP |
| 6 | Очистка по сроку | M1–M4 | Memory → БД | по расписанию |

## Данные

`M3Record` — состояние работы по задаче:

```json
{ "issue_key": "MKT-42", "scope": "issue", "agent": "analyst", "updated_at": "2026-10-10T12:05:00Z",
  "done": ["Раздел «Проблема»", "Раздел «Ограничения»"],
  "next": ["Критерии приёмки"],
  "blockers": ["Не ясен формат выгрузки — спросить в комментарии"] }
```

Профиль памяти:

```yaml
profile: default
read: [M1, M2, M3, M5, M6]
write: [M3]
m2_last_runs: 3
retention: { M1: 30d, M2: 180d, M3: until_issue_closed }
```
