## Истории

### US-OBS-01

**Как** пользователь icplan, **я хочу** видеть шаги агента в задаче, **чтобы** понимать ход работы.

**Критерии приёмки:**

- [ ] Шаги по мере работы
- [ ] Несколько запусков разделены

**Требования:** [Таймлайн в задаче](../../openspec/changes/define-agent-platform/specs/observability/spec.md) · [События запуска](../../openspec/changes/define-agent-platform/specs/observability/spec.md)

### US-OBS-02

**Как** администратор платформы, **я хочу** разобрать задачу: все запуски, версии агентов, итоги, **чтобы** находить причины проблем.

**Критерии приёмки:**

- [ ] Задача → все запуски с версиями

**Требования:** [Трассировка](../../openspec/changes/define-agent-platform/specs/observability/spec.md)

### US-OBS-03

**Как** эксплуатация, **я хочу** чтобы в событиях не было секретов, **чтобы** журнал не стал утечкой.

**Критерии приёмки:**

- [ ] Секрет в аргументах → маскируется
- [ ] Неизвестный формат секрета → маскирование по шаблонам

**Требования:** [Маскирование чувствительных данных](../../openspec/changes/define-agent-platform/specs/observability/spec.md)
