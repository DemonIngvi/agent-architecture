## Истории

### US-OBS-01 {#us-obs-01}

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** видеть шаги агента в задаче, **чтобы** понимать, что он делал.

**Точка входа:** карточка задачи

**Участвует в цепочках ICPlan:** [US-ICP-01](icplan.md#us-icp-01), [US-ICP-08](icplan.md#us-icp-08), [US-ICP-19](icplan.md#us-icp-19), [US-ICP-02](icplan.md#us-icp-02), [US-ICP-10](icplan.md#us-icp-10), [US-ICP-04](icplan.md#us-icp-04)

**Критерии приёмки:**

- [ ] Чат запуска: шаги, тулы, итог
- [ ] Длинный вывод свёрнут
- [ ] Событий нет → «запуск не начался» с причиной

**Требования:** [Чат запуска в задаче](../../openspec/changes/define-agent-platform/specs/observability/spec.md#r-obs-02) · [События запуска](../../openspec/changes/define-agent-platform/specs/observability/spec.md#r-obs-01)

### US-OBS-02 {#us-obs-02}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** разобрать задачу: все запуски, версии агентов, итоги, **чтобы** найти причину плохого результата.

**Точка входа:** карточка задачи → запуски

**Критерии приёмки:**

- [ ] Список запусков задачи с версией агента и итогом
- [ ] Переход к событиям запуска
- [ ] События старше срока хранения → только итог

**Требования:** [События запуска](../../openspec/changes/define-agent-platform/specs/observability/spec.md#r-obs-01) · [Политика хранения](../../openspec/changes/define-agent-platform/specs/observability/spec.md#r-obs-06)

### US-OBS-03 {#us-obs-03}

**Как** безопасность ([персона Б](personas.md#б-безопасность)), **я хочу** чтобы в событиях не было секретов, **чтобы** не было утечки через журналы.

**Точка входа:** —

**Участвует в цепочках ICPlan:** [US-ICP-02](icplan.md#us-icp-02)

**Критерии приёмки:**

- [ ] Секреты маскируются при записи
- [ ] Новый шаблон секрета → применяется к новым событиям
- [ ] Маскирование не сработало → событие помечается и скрывается

**Требования:** [Маскирование чувствительных данных](../../openspec/changes/define-agent-platform/specs/observability/spec.md#r-obs-04)

### US-OBS-04 {#us-obs-04}

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** проследить сбойный запуск через все компоненты, **чтобы** быстро найти, где сломалось.

**Точка входа:** журнал / трассы

**Критерии приёмки:**

- [ ] Трасса запуска: Runner → Harness → LiteLLM → тулы
- [ ] Переход из задачи к трассе
- [ ] Трасса неполная → видно, на каком компоненте оборвалась

**Требования:** [Трассировка](../../openspec/changes/define-agent-platform/specs/observability/spec.md#r-obs-03)

### US-OBS-05 {#us-obs-05}

**Как** владелец продукта ([персона ВП](personas.md#вп-владелец-продукта)), **я хочу** видеть, сколько работы сделали агенты и во что она обошлась, **чтобы** оценивать пользу платформы.

**Точка входа:** дашборд

**Участвует в цепочках ICPlan:** [US-ICP-12](icplan.md#us-icp-12), [US-ICP-28](icplan.md#us-icp-28)

**Критерии приёмки:**

- [ ] Закрыто задач агентами, доля возвратов, время в работе, затраты по периодам
- [ ] Разбивка по проектам и агентам
- [ ] Нет данных → нули

**Требования:** [Сводка и статистика агентов](../../openspec/changes/define-agent-platform/specs/observability/spec.md#r-obs-13) · [Затраты](../../openspec/changes/define-agent-platform/specs/observability/spec.md#r-obs-05)
