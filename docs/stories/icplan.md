## Истории

### US-ICP-01

**Как** пользователь icplan, **я хочу** перевести задачу в статус и чтобы агент сам её взял, **чтобы** не делегировать вручную на каждом этапе.

**Критерии приёмки:**

- [ ] Статус с агентом-делегатом → запуск в очереди
- [ ] Статус без агента → ничего не происходит
- [ ] Агент не участник проекта → запуск не создаётся, предупреждение в истории
- [ ] Повторный вход в статус при активном запуске → второго запуска нет

**Требования:** [Агент-делегат статуса](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Защита от дублей](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Поведение при отказах зависимостей](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md)

### US-ICP-02

**Как** пользователь icplan, **я хочу** видеть, как агент работает над задачей, **чтобы** понимать прогресс и вовремя вмешаться.

**Критерии приёмки:**

- [ ] Шаги появляются в задаче по мере работы
- [ ] Обрыв связи → пропущенные шаги досылаются без дублей
- [ ] Итог — комментарием агента, файлы — вложениями

**Требования:** [Стрим шагов и итог в задачу](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md) · [Таймлайн в задаче](../../openspec/changes/define-agent-platform/specs/observability/spec.md)

### US-ICP-03

**Как** пользователь icplan, **я хочу** получить уведомление, когда агент ждёт моего решения, **чтобы** не держать агента в ожидании.

**Критерии приёмки:**

- [ ] Запрос подтверждения → уведомление исполнителю задачи
- [ ] Нет прав на подтверждение → кнопка недоступна, решение не принимается
- [ ] Истёк таймаут ожидания → действие отклонено, запись в истории

**Требования:** [Подтверждения и ответы](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md) · [Уведомление о решении пользователя](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md)

### US-ICP-04

**Как** пользователь icplan, **я хочу** отменить работу агента, **чтобы** остановить неверное направление и траты.

**Критерии приёмки:**

- [ ] Отмена активного запуска → `cancelled`, среда уничтожена
- [ ] Отмена в очереди → запуск снят без среды
- [ ] Отмена завершённого → без изменений

**Требования:** [Отмена из ICPlan](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md) · [Отмена запуска](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md)

### US-ICP-05

**Как** администратор платформы, **я хочу** настроить процесс: статусы, типы, действия с агентами, **чтобы** процесс работал без кода.

**Критерии приёмки:**

- [ ] Агент в статусе / типе / действии сохраняется
- [ ] Конфликт правил → приоритет явный → статус → тип → действие
- [ ] Агент удалён из проекта → правила очищаются

**Требования:** [Приоритет правил](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Очистка при выходе агента из проекта](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Определение агента](../../openspec/changes/define-agent-platform/specs/agent-registry/spec.md)

### US-ICP-06

**Как** эксплуатация, **я хочу** видеть, в сети ли платформа агентов, **чтобы** понимать, почему задачи не берутся.

**Критерии приёмки:**

- [ ] Runner не опрашивает очередь дольше порога → агенты «не в сети»
- [ ] Несовместимая версия протокола → предупреждение

**Требования:** [Каталог агентов платформы](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md) · [Версия протокола](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md)
