| Удалён: шаги ручные | ICPlan | задача | → Агент обновлён | шаги процессов без агента |
| Агент обновлён | ICPlan | конец | — | — |

## Истории

### US-ICP-01 {#us-icp-01}

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** создать задачу нужного типа и чтобы она сама прошла шаги процесса с агентами, **чтобы** не делегировать и не переводить задачу вручную на каждом этапе.

**Точка входа:** создание задачи: доска, Telegram-бот, API; перевод в колонку

**Критерии приёмки:**

- [ ] Задача вошла в шаг с агентом → агент — делегат, запуск в его очереди
- [ ] Успех запуска → ICPlan переводит задачу на следующий шаг
- [ ] Ошибка или непройденный quality gate → переход при ошибке, уведомление владельцу процесса
- [ ] Ручной шаг → задача ждёт человека
- [ ] Лимит запусков на шаге превышен → переход при ошибке
- [ ] Повторный вход в шаг при активном запуске → второго запуска нет

**Требования:** [Агент шага процесса](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Переход по итогу запуска](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Защита от дублей](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Поведение при отказах зависимостей](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md)

### US-ICP-08 {#us-icp-08}

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** сам поручить задачу конкретному агенту, минуя процесс, **чтобы** быстро отдать разовую работу нужному агенту.

**Точка входа:** карточка задачи: поле «делегат»

**Критерии приёмки:**
