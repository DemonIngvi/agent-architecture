## Истории

### US-ICP-01

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** создать задачу нужного типа и чтобы она сама прошла шаги процесса с агентами, **чтобы** не делегировать и не переводить задачу вручную на каждом этапе.

**Критерии приёмки:**

- [ ] Задача вошла в шаг с агентом → агент — делегат, запуск в его очереди
- [ ] Успех запуска → ICPlan переводит задачу на следующий шаг
- [ ] Ошибка или непройденный quality gate → переход при ошибке, уведомление владельцу процесса
- [ ] Ручной шаг → задача ждёт человека
- [ ] Лимит запусков на шаге превышен → переход при ошибке
- [ ] Повторный вход в шаг при активном запуске → второго запуска нет

**Требования:** [Агент шага процесса](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Переход по итогу запуска](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Защита от дублей](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Поведение при отказах зависимостей](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md)

### US-ICP-02

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** видеть, как агент работает над задачей, **чтобы** понимать прогресс и вовремя вмешаться.

**Критерии приёмки:**

- [ ] Шаги появляются в задаче по мере работы
- [ ] Обрыв связи → пропущенные шаги досылаются без дублей
- [ ] Итог — комментарием агента, файлы — вложениями

**Требования:** [Стрим шагов и итог в задачу](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md) · [Таймлайн в задаче](../../openspec/changes/define-agent-platform/specs/observability/spec.md)

### US-ICP-03

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** получить уведомление, когда агент ждёт моего решения, **чтобы** не держать агента в ожидании.

**Критерии приёмки:**

- [ ] Запрос подтверждения → уведомление исполнителю задачи
- [ ] Нет прав на подтверждение → кнопка недоступна, решение не принимается
- [ ] Истёк таймаут ожидания → действие отклонено, запись в истории

**Требования:** [Подтверждения и ответы](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md) · [Уведомление о решении пользователя](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md)

### US-ICP-04

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** отменить работу агента, **чтобы** остановить неверное направление и траты.

**Критерии приёмки:**

- [ ] Отмена активного запуска → `cancelled`, среда уничтожена
- [ ] Отмена в очереди → запуск снят без среды
- [ ] Отмена завершённого → без изменений

**Требования:** [Отмена из ICPlan](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md) · [Отмена запуска](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md)

### US-ICP-05

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** настроить процесс для типа задачи: шаги-колонки, агентов, переходы при успехе и ошибке, следующий процесс, **чтобы** процесс работал без кода и однозначно.

**Критерии приёмки:**

- [ ] Процесс сохраняется, у каждого шага одна колонка и явные переходы
- [ ] Ошибка структуры (несуществующий шаг, повтор колонки, недостижимый шаг) → сохранение отклонено с причиной
- [ ] Переход в другой процесс → тип задачи меняется, задача на первом шаге нового процесса
- [ ] Конфликт правил → явный делегат → шаг процесса → Действие
- [ ] Агент удалён из проекта → его шаги становятся ручными

**Требования:** [Определение процесса](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Тип задачи задаёт процесс](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Приоритет правил](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Очистка при выходе агента из проекта](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Определение агента](../../openspec/changes/define-agent-platform/specs/agent-registry/spec.md)

### US-ICP-07

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** брать следующую задачу из своей очереди по всем процессам, где я исполнитель шага, **чтобы** работать без ручной раздачи и не брать одну задачу дважды.

**Критерии приёмки:**

- [ ] Порядок очереди: приоритет задачи, затем время постановки
- [ ] У задачи не более одного активного запуска
- [ ] Runner пропал → по истечении аренды запуск снова в голове очереди

**Требования:** [Очередь агента](../../openspec/changes/icplan-agent-autopickup/specs/icplan-agent-autopickup/spec.md) · [Однократная выдача запуска](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md)

### US-ICP-06

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** видеть, в сети ли платформа агентов, **чтобы** понимать, почему задачи не берутся.

**Критерии приёмки:**

- [ ] Runner не опрашивает очередь дольше порога → агенты «не в сети»
- [ ] Несовместимая версия протокола → предупреждение

**Требования:** [Каталог агентов платформы](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md) · [Версия протокола](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md)
