## Истории

### US-PM-01 {#us-pm-01}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** задать агенту бюджет, профиль среды и памяти, **чтобы** контролировать траты и возможности агента.

**Точка входа:** агент → вкладка «Платформа»

**Критерии приёмки:**

- [ ] Сохранение → видно в карточке агента
- [ ] Неверное значение → ошибка с полем
- [ ] Выше потолка платформы → применяется потолок

**Требования:** [Настройки агента](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md) · [Конфигурация модуля](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md)

### US-PM-02 {#us-pm-02}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** менять настройки без влияния на работающих агентов, **чтобы** не прерывать идущие задачи.

**Точка входа:** агент → вкладка «Платформа»

**Критерии приёмки:**

- [ ] Изменение → со следующего запуска
- [ ] Активный запуск — на старых настройках
- [ ] Откат на прежнюю версию → тоже со следующего запуска

**Требования:** [Применение к следующему запуску](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md)

### US-PM-03 {#us-pm-03}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** перенести агента из dev в prod, **чтобы** не настраивать заново.

**Точка входа:** агент → экспорт / импорт

**Критерии приёмки:**

- [ ] Экспорт YAML → импорт → такой же агент
- [ ] Ссылка на несуществующий тул → импорт с ошибкой по полю
- [ ] Импорт поверх существующего → новая версия, не замена

**Требования:** [Экспорт и импорт YAML](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md) · [Источник правды и экспорт](../../openspec/changes/define-agent-platform/specs/agent-registry/spec.md)

### US-PM-04 {#us-pm-04}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** чтобы настройки дошли до LiteLLM и OPA, **чтобы** бюджеты и правила действовали без ручной синхронизации.

**Точка входа:** сохранение настроек

**Критерии приёмки:**

- [ ] Сохранил бюджет → ключ LiteLLM обновлён
- [ ] LiteLLM или OPA недоступен → предупреждение, повтор, прежнее значение действует
- [ ] Расхождение найдено сверкой → предупреждение администратору

**Требования:** [Раздача настроек исполнителям](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md) · [Поведение при отказах зависимостей](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md)

### US-PM-05 {#us-pm-05}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** назначить агенту уровень автономии R0–R5, **чтобы** агент спрашивал подтверждение ровно там, где нужно.

**Точка входа:** агент → вкладка «Платформа»

**Критерии приёмки:**

- [ ] Уровень сохранён → со следующего запуска действует политика подтверждений
- [ ] R0 → агент только предлагает, действий нет
- [ ] Уровень выше разрешённого для проекта → отклонено

**Требования:** [Уровень автономии агента](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md) · [Настройки агента](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md)

### US-PM-06 {#us-pm-06}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** задать бюджеты команды и проекта и получить предупреждение при приближении к лимиту, **чтобы** не узнавать о перерасходе постфактум.

**Точка входа:** Настройки проекта → Платформа

**Критерии приёмки:**

- [ ] Бюджет проекта сохранён → сумма бюджетов агентов не выше него
- [ ] Достигнуто 80% → уведомление администратору
- [ ] Исчерпан → новые запуски отклоняются G1 с причиной

**Требования:** [Иерархия бюджетов токенов и денег](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md) · [G1 Admission](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md)

### US-PM-07 {#us-pm-07}

**Как** безопасность ([персона Б](personas.md#б-безопасность)), **я хочу** видеть, кто и когда менял настройки агентов и политики, **чтобы** расследовать инциденты и проверять изменения прав.

**Точка входа:** Настройки → журнал изменений

**Критерии приёмки:**

- [ ] Список изменений: кто, когда, что было и что стало
- [ ] Фильтр по агенту и периоду
- [ ] Изменение через импорт YAML → тоже в журнале

**Требования:** [Версии определения агента](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md) · [Права на настройки](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md)
