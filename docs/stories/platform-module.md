## Истории

### US-PM-01

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** задать агенту бюджет, профиль среды и памяти, **чтобы** контролировать траты и возможности агента.

**Критерии приёмки:**

- [ ] Сохранение → видно в карточке агента
- [ ] Неверное значение → ошибка с полем
- [ ] Выше потолка платформы → применяется потолок

**Требования:** [Настройки агента](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md) · [Конфигурация модуля](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md)

### US-PM-02

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** менять настройки без влияния на работающих агентов, **чтобы** не ломать активные запуски.

**Критерии приёмки:**

- [ ] Изменение → действует со следующего запуска
- [ ] Запуск в очереди → стартует с новыми настройками

**Требования:** [Применение к следующему запуску](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md)

### US-PM-03

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** перенести агента из dev в prod, **чтобы** не настраивать заново.

**Критерии приёмки:**

- [ ] Экспорт YAML без секретов
- [ ] Импорт → новая версия
- [ ] Битая ссылка → импорт отклонён

**Требования:** [Экспорт и импорт YAML](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md) · [Версии определения агента](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md)

### US-PM-04

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** чтобы настройки дошли до LiteLLM и OPA, **чтобы** лимиты и правила реально действовали.

**Критерии приёмки:**

- [ ] LiteLLM недоступен → «не применено» и повтор
- [ ] Рассинхронизация → предупреждение

**Требования:** [Раздача настроек исполнителям](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md) · [Поведение при отказах зависимостей](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md)

### US-PM-05

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** назначить агенту уровень автономии R0–R5, **чтобы** решать, что агент делает сам.

**Критерии приёмки:**

- [ ] Уровень сохраняется и попадает в данные OPA
- [ ] Необратимые действия в prod всегда ждут подтверждения

**Требования:** [Уровень автономии агента](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md) · [Настройки агента](../../openspec/changes/define-agent-platform/specs/control-plane/spec.md)
