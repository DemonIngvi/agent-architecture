## Истории

### US-MCP-01 {#us-mcp-01}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** подключить агенту новый MCP-сервер без кода, **чтобы** расширять возможности агента.

**Точка входа:** Команда → MCP-серверы

**Критерии приёмки:**

- [ ] Регистрация сервера → тулы доступны выбранным агентам
- [ ] Сервер недоступен при регистрации → ошибка
- [ ] Отключение сервера → тулы пропадают со следующего запуска

**Требования:** [Регистрация MCP-сервера](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md) · [Ограничение набора тулов](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md)

### US-MCP-02 {#us-mcp-02}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** вызвать тул и получить понятную ошибку при сбое, **чтобы** решить, повторять или идти иначе.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Таймаут → ошибка с типом
- [ ] Ошибка сервера → текст ошибки агенту
- [ ] Тул не в наборе агента → отказ без вызова

**Требования:** [Таймауты и ошибки тулов](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md) · [Ограничение набора тулов](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md)

### US-MCP-03 {#us-mcp-03}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** чтобы рабочий агент не видел административных тулов, **чтобы** агент не мог менять настройки платформы.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Админ-тулы не в наборе рабочих агентов
- [ ] Попытка вызова → отказ
- [ ] Админ-агент — отдельная роль с аудитом

**Требования:** [Административные тулы отделены](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md)

### US-MCP-04 {#us-mcp-04}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** дать агенту навык (skill), **чтобы** агент работал по готовой процедуре.

**Точка входа:** Команда → навыки

**Критерии приёмки:**

- [ ] Навык привязан → в контексте агента
- [ ] Навык изменён → со следующего запуска
- [ ] Навык удалён → отвязан у всех агентов

**Требования:** [Скиллы](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md)

### US-MCP-05 {#us-mcp-05}

**Как** безопасность ([персона Б](personas.md#б-безопасность)), **я хочу** видеть, какие тулы может вызвать каждый агент, **чтобы** проверять права агентов.

**Точка входа:** Команда → ИИ-агенты → доступы

**Критерии приёмки:**

- [ ] Список агент × тулы × серверы
- [ ] Тул с записью во внешнюю систему помечен
- [ ] Изменение набора → в журнале изменений

**Требования:** [Ограничение набора тулов](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md)
