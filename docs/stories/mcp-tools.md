## Истории

### US-MCP-01

**Как** администратор платформы, **я хочу** подключить агенту новый MCP-сервер без кода, **чтобы** расширять возможности агентов.

**Критерии приёмки:**

- [ ] Регистрация → тулы доступны после allowlist
- [ ] Сервер недоступен → пометка, тулы не выдаются

**Требования:** [Регистрация MCP-сервера](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md) · [Ограничение набора тулов](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md)

### US-MCP-02

**Как** агент (система), **я хочу** вызвать тул и получить понятную ошибку при сбое, **чтобы** продолжить работу.

**Критерии приёмки:**

- [ ] Таймаут → ошибка тула, цикл продолжается
- [ ] Большой ответ → обрезка

**Требования:** [Таймауты и ошибки тулов](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md)

### US-MCP-03

**Как** администратор платформы, **я хочу** чтобы рабочий агент не видел административных тулов, **чтобы** не было случайных изменений бюджета и политик.

**Критерии приёмки:**

- [ ] Админ-тулы скрыты
- [ ] Вызов по имени → отказ

**Требования:** [Административные тулы отделены](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md)
