## Истории

### US-MEM-01 {#us-mem-01}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** знать, что сделал предыдущий агент по задаче, **чтобы** не повторять работу.

**Точка входа:** контекст запуска

**Критерии приёмки:**

- [ ] Состояние задачи M3 в контексте
- [ ] M3 пусто → работа с нуля
- [ ] Конфликт записи M3 → последняя версия, прежняя в истории

**Требования:** [Состояние задачи M3](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md)

### US-MEM-02 {#us-mem-02}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** видеть итоги прошлых запусков задачи и заметки пользователя о возврате, **чтобы** учесть замечания и не повторять ошибок.

**Точка входа:** контекст запуска

**Критерии приёмки:**

- [ ] Итоги последних N запусков в контексте
- [ ] Возврат пользователем → заметка возврата в контексте
- [ ] Память недоступна → пустой контекст с предупреждением

**Требования:** [История запусков в контексте](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md) · [Автоматическая запись M1 и M2](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md)

### US-MEM-03 {#us-mem-03}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** удалить или исправить ошибочную память, **чтобы** агент не повторял неверное.

**Точка входа:** агент → память

**Критерии приёмки:**

- [ ] Удаление записи → не попадает в контекст
- [ ] Исправление → новая версия
- [ ] Удаление по сроку хранения → автоматически

**Требования:** [Управление памятью](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md) · [Срок хранения](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md)

### US-MEM-04 {#us-mem-04}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** ограничить, что агент видит из памяти, **чтобы** не было утечки между проектами.

**Точка входа:** агент → вкладка «Платформа»

**Критерии приёмки:**

- [ ] Профиль памяти задаёт уровни чтения и записи
- [ ] Чужой проект → недоступно
- [ ] Профиль не задан → по умолчанию из L0

**Требования:** [Область видимости как атрибут](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md)
