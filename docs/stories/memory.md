## Истории

### US-MEM-01

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** знать, что сделал предыдущий агент по задаче, **чтобы** продолжить, а не начать заново.

**Критерии приёмки:**

- [ ] M3 есть → в контексте
- [ ] M3 нет → работа с нуля
- [ ] Конфликт записи → последняя версия, прежняя в истории

**Требования:** [Состояние задачи M3](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md)

### US-MEM-02

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** видеть итоги прошлых запусков задачи, **чтобы** не повторять ошибки.

**Критерии приёмки:**

- [ ] Итоги последних N запусков в контексте
- [ ] Нет истории → пустой раздел

**Требования:** [История запусков в контексте](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md) · [Автоматическая запись M1 и M2](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md)

### US-MEM-03

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** удалить или исправить ошибочную память, **чтобы** агенты не опирались на неверные факты.

**Критерии приёмки:**

- [ ] Удаление → следующие запуски не получают запись
- [ ] Нет прав → отказ

**Требования:** [Управление памятью](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md)

### US-MEM-04

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** ограничить, что агент видит из памяти, **чтобы** не было утечки между проектами.

**Критерии приёмки:**

- [ ] Чужая область → отказ
- [ ] Запись в чужую область → отказ и аудит

**Требования:** [Область видимости как атрибут](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md)
