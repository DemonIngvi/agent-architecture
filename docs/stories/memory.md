## Истории

### US-MEM-05 {#us-mem-05}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** работать в рабочем контексте запуска (M0) и не переполнить окно модели, **чтобы** доводить длинную задачу до конца.

**Точка входа:** агентский цикл Harness

**Критерии приёмки:**

- [ ] M0 собирается Harness на каждом шаге: сообщения, вывод тулов
- [ ] Заполнение 80% окна → сжатие истории, итог сжатия в M0
- [ ] Запуск завершён → M0 уничтожается вместе со средой, не сохраняется

**Требования:** [Уровни памяти M0–M6](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-01) · [Управление контекстом](../../openspec/changes/define-agent-platform/specs/agent-harness/spec.md#r-hrn-07)

### US-MEM-06 {#us-mem-06}

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** чтобы агент помнил нашу переписку по задаче и в чате (M1), **чтобы** не повторять уже сказанное.

**Точка входа:** чат агента, комментарии задачи

**Участвует в цепочках ICPlan:** [US-ICP-09](icplan.md#us-icp-09), [US-ICP-10](icplan.md#us-icp-10), [US-ICP-11](icplan.md#us-icp-11)

**Критерии приёмки:**

- [ ] Каждое сообщение пользователя и агента ICPlan пишет в M1 автоматически
- [ ] Новый запуск по задаче получает переписку, если M1 в профиле чтения
- [ ] Переписка старше срока M1 не отдаётся агенту; треды удаляет ICPlan по `chat.retention_days` (D25)

**Требования:** [Автоматическая запись M1 и M2](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-03) · [Срок хранения](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-08) · [Проверки записи в память](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-15)

### US-MEM-01 {#us-mem-01}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** знать, что сделал предыдущий агент по задаче, **чтобы** не повторять работу.

**Точка входа:** контекст запуска

**Участвует в цепочках ICPlan:** [US-ICP-01](icplan.md#us-icp-01), [US-ICP-29](icplan.md#us-icp-29)

**Критерии приёмки:**

- [ ] Состояние задачи M3 в контексте
- [ ] M3 пусто → работа с нуля
- [ ] Конфликт записи M3 → последняя версия, прежняя в истории

**Требования:** [Состояние задачи M3](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-04) · [Проверки записи в память](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-15)

### US-MEM-02 {#us-mem-02}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** видеть итоги прошлых запусков задачи и заметки пользователя о возврате, **чтобы** учесть замечания и не повторять ошибок.

**Точка входа:** контекст запуска

**Участвует в цепочках ICPlan:** [US-ICP-13](icplan.md#us-icp-13), [US-ICP-16](icplan.md#us-icp-16), [US-ICP-29](icplan.md#us-icp-29)

**Критерии приёмки:**

- [ ] Итоги последних N запусков в контексте
- [ ] Возврат пользователем → заметка возврата в контексте
- [ ] Память недоступна → пустой контекст с предупреждением

**Требования:** [История запусков в контексте](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-05) · [Автоматическая запись M1 и M2](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-03)

### US-MEM-03 {#us-mem-03}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** удалить или исправить ошибочную память, **чтобы** агент не повторял неверное.

**Точка входа:** агент → память

**Критерии приёмки:**

- [ ] Удаление записи → не попадает в контекст
- [ ] Исправление → новая версия
- [ ] Удаление по сроку хранения → автоматически

**Требования:** [Управление памятью](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-07) · [Срок хранения](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-08)

### US-MEM-04 {#us-mem-04}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** ограничить, что агент видит из памяти, **чтобы** не было утечки между проектами.

**Точка входа:** карточка агента → «Платформа»

**Критерии приёмки:**

- [ ] Профиль памяти задаёт уровни чтения и записи
- [ ] Чужой проект → недоступно
- [ ] Профиль не задан → по умолчанию из L0

**Требования:** [Область видимости как атрибут](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-02)

### US-MEM-07 {#us-mem-07}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** получить свою инструкцию и навыки (M5) нужной версии при старте, **чтобы** работать по правилам своей роли.

**Точка входа:** определение агента (Registry)

**Участвует в цепочках ICPlan:** [US-ICP-01](icplan.md#us-icp-01), [US-ICP-21](icplan.md#us-icp-21)

**Критерии приёмки:**

- [ ] Harness собирает агента из определения: инструкция и навыки версии запуска
- [ ] Администратор изменил инструкцию → новый запуск получает новую версию
- [ ] Навык удалён из каталога → запуск без него, предупреждение в событиях

**Требования:** [Уровни памяти M0–M6](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-01) · [Инициализация из определения агента](../../openspec/changes/define-agent-platform/specs/agent-harness/spec.md#r-hrn-01)

### US-MEM-08 {#us-mem-08}

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** чтобы агент опирался на документы проекта (M6), а не просил пересказать, **чтобы** результат соответствовал принятым в проекте правилам.

**Точка входа:** документы проекта ICPlan

**Участвует в цепочках ICPlan:** [US-ICP-29](icplan.md#us-icp-29)

**Критерии приёмки:**

- [ ] Агент читает документ проекта тулом `get_document`
- [ ] Записать в документ проекта агент не может
- [ ] Документ недоступен по правам → агент сообщает и продолжает без него

**Требования:** [Уровни памяти M0–M6](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-01) · [MCP-сервер ICPlan](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md#r-mcp-13)

### US-MEM-09 {#us-mem-09}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** находить факты по смыслу из прошлых работ (M4), **чтобы** не терять знания между задачами.

**Точка входа:** тул поиска (после MVP)

**Критерии приёмки:**

- [ ] После MVP: поиск фактов по смыслу в своей области видимости
- [ ] До MVP: уровень M4 недоступен, профиль с M4 не сохраняется
- [ ] Факт из чужого проекта не возвращается

**Требования:** [Семантическая память M4 — после MVP](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-06) · [Область видимости как атрибут](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-02)

### US-MEM-10 {#us-mem-10}

**Как** безопасность ([персона Б](personas.md#б-безопасность)), **я хочу** чтобы переписка, итоги и состояния удалялись по срокам хранения, **чтобы** не хранить лишние данные и персональные данные.

**Точка входа:** расписание очистки

**Критерии приёмки:**

- [ ] Память не отдаёт M1 и M2 старше срока профиля (M1 30 д, M2 180 д); M3 удаляется по профилю после закрытия задачи; запуски и треды чата удаляет ICPlan по `runs.retention_days` и `chat.retention_days` (D25)
- [ ] Удаление попадает в журнал
- [ ] Очистка не прошла → повтор и уведомление эксплуатации

**Требования:** [Срок хранения](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-08) · [Управление памятью](../../openspec/changes/define-agent-platform/specs/agent-memory/spec.md#r-mem-07) · [Очистка запусков и переписки по сроку](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md#r-icp-19)
