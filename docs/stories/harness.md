## Истории

### US-HAR-01 {#us-har-01}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** выполнить задачу по инструкции, используя модель и тулы, **чтобы** дать пользователю результат.

**Точка входа:** задание `RunBundle`

**Участвует в цепочках ICPlan:** [US-ICP-01](icplan.md#us-icp-01), [US-ICP-08](icplan.md#us-icp-08), [US-ICP-09](icplan.md#us-icp-09), [US-ICP-19](icplan.md#us-icp-19), [US-ICP-02](icplan.md#us-icp-02), [US-ICP-16](icplan.md#us-icp-16), [US-ICP-24](icplan.md#us-icp-24)

**Критерии приёмки:**

- [ ] Цикл модель → тулы → итог
- [ ] Тул вернул ошибку → агент учитывает и продолжает
- [ ] Модель недоступна → fallback или завершение `error` с причиной

**Требования:** [Агентский цикл](../../openspec/changes/define-agent-platform/specs/agent-harness/spec.md#r-hrn-02) · [Инициализация из определения агента](../../openspec/changes/define-agent-platform/specs/agent-harness/spec.md#r-hrn-01) · [MCP-сервер ICPlan](../../openspec/changes/define-agent-platform/specs/tool-integration/spec.md#r-mcp-13)

### US-HAR-02 {#us-har-02}

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** подтвердить опасное действие агента, **чтобы** агент не сделал необратимого без меня.

**Точка входа:** карточка задачи, уведомление

**Участвует в цепочках ICPlan:** [US-ICP-03](icplan.md#us-icp-03)

**Критерии приёмки:**

- [ ] Опасное действие → пауза, запрос в задаче
- [ ] Одобрено → выполняется
- [ ] Отклонено или таймаут → не выполняется, агент продолжает без него

**Требования:** [Пауза и возобновление](../../openspec/changes/define-agent-platform/specs/agent-harness/spec.md#r-hrn-05) · [G2 Action](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md#r-grd-03)

### US-HAR-03 {#us-har-03}

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** получить проверенный результат, **чтобы** не проверять очевидное вручную.

**Точка входа:** итог запуска

**Критерии приёмки:**

- [ ] Итог проверяется по критериям приёмки задачи
- [ ] Не прошёл → агент дорабатывает в пределах лимита
- [ ] Лимит исчерпан → `failed` с отчётом проверки

**Требования:** [Quality gate результата](../../openspec/changes/define-agent-platform/specs/agent-harness/spec.md#r-hrn-08)

### US-HAR-04 {#us-har-04}

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** чтобы агент не зацикливался и не тратил лишнее, **чтобы** контролировать затраты.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Повтор одинакового вызова N раз → стоп с причиной
- [ ] Лимит шагов или времени → `limit`
- [ ] Резкий рост расхода → стоп и уведомление

**Требования:** [Защита от зацикливания](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md#r-grd-09) · [Лимит шагов и времени](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md#r-grd-10) · [Аномальный расход](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md#r-grd-12)

### US-HAR-05 {#us-har-05}

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** чтобы падение процесса не теряло работу, **чтобы** не перезапускать с нуля.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Checkpoint после каждого шага
- [ ] Перезапуск → продолжение с последнего checkpoint
- [ ] Checkpoint недоступен → опасные действия отклоняются, событие

**Требования:** [Пауза и возобновление](../../openspec/changes/define-agent-platform/specs/agent-harness/spec.md#r-hrn-05) · [Поведение при отказах зависимостей](../../openspec/changes/define-agent-platform/specs/agent-harness/spec.md#r-hrn-13)

### US-HAR-06 {#us-har-06}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** получить указание пользователя во время работы и учесть его, **чтобы** не уйти в неверную сторону до конца запуска.

**Точка входа:** чат задачи (US-ICP-10)

**Участвует в цепочках ICPlan:** [US-ICP-10](icplan.md#us-icp-10)

**Критерии приёмки:**

- [ ] Сообщение пользователя → включается в контекст на следующем шаге
- [ ] Сообщение «стоп» → завершение с итогом сделанного
- [ ] Сообщение во время вызова тула → после его завершения

**Требования:** [Указания пользователя в цикле](../../openspec/changes/define-agent-platform/specs/agent-harness/spec.md#r-hrn-16) · [Указания пользователя во время запуска](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md#r-icp-16)

### US-HAR-07 {#us-har-07}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** задать пользователю вопрос и подождать ответа, **чтобы** не гадать при неясном задании.

**Точка входа:** —

**Участвует в цепочках ICPlan:** [US-ICP-11](icplan.md#us-icp-11), [US-ICP-03](icplan.md#us-icp-03)

**Критерии приёмки:**

- [ ] Вопрос → пауза `waiting`, слот модели свободен
- [ ] Ответ → продолжение с ответом в контексте
- [ ] Таймаут → завершение с причиной «нет ответа»

**Требования:** [Пауза и возобновление](../../openspec/changes/define-agent-platform/specs/agent-harness/spec.md#r-hrn-05) · [Подтверждения и ответы](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md#r-icp-05)
