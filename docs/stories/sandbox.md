## Истории

### US-SBX-01 {#us-sbx-01}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** получить чистую среду за доли секунды, **чтобы** запуск начинался сразу.

**Точка входа:** —

**Участвует в цепочках ICPlan:** [US-ICP-01](icplan.md#us-icp-01), [US-ICP-14](icplan.md#us-icp-14), [US-ICP-04](icplan.md#us-icp-04)

**Критерии приёмки:**

- [ ] Есть тёплый контейнер → старт < 1 с
- [ ] Пул пуст → холодный старт, событие
- [ ] Контейнер после запуска уничтожается, не переиспользуется

**Требования:** [Тёплый пул](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md#r-sbx-02) · [Среда на каждый запуск](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md#r-sbx-01)

### US-SBX-02 {#us-sbx-02}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** дать агенту доступ только к нужным репозиториям, **чтобы** агент не трогал чужой код.

**Точка входа:** агент → доступы

**Критерии приёмки:**

- [ ] Репозиторий в allowlist → клон в `/workspace`
- [ ] Не в allowlist → отказ, событие
- [ ] Push в защищённую ветку → отклонён, работа через PR

**Требования:** [Доступ к репозиториям](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md#r-sbx-04) · [Секреты](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md#r-sbx-07)

### US-SBX-03 {#us-sbx-03}

**Как** безопасность ([персона Б](personas.md#б-безопасность)), **я хочу** чтобы агент не мог отправить данные в интернет, **чтобы** не было утечки.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Домен не в allowlist → соединение отклонено
- [ ] Разрешённый домен → через egress-прокси с журналом
- [ ] Прямой выход мимо прокси → заблокирован сетевой политикой

**Требования:** [Сетевая изоляция](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md#r-sbx-06) · [G3 Isolation](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md#r-grd-04)

### US-SBX-04 {#us-sbx-04}

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** получить файлы, созданные агентом, **чтобы** пользоваться результатом в задаче.

**Точка входа:** карточка задачи: вложения, ссылка на PR

**Критерии приёмки:**

- [ ] Файлы итога → вложения задачи
- [ ] Код → PR со ссылкой в задаче
- [ ] Файл больше лимита или с секретом → не прикладывается, пометка в итоге

**Требования:** [Эфемерный workspace](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md#r-sbx-03)

### US-SBX-05 {#us-sbx-05}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** получить результат предыдущего агента в своём рабочем пространстве, **чтобы** продолжить работу, а не начинать заново.

**Точка входа:** манифест workspace запуска

**Участвует в цепочках ICPlan:** [US-ICP-01](icplan.md#us-icp-01)

**Критерии приёмки:**

- [ ] Workspace задачи содержит артефакты прошлых шагов (чтение)
- [ ] Своя подпапка шага — запись
- [ ] Нет доступа к workspace по политике → отказ с причиной

**Требования:** [Подключение рабочего пространства по манифесту](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md#r-sbx-14) · [Рабочее пространство в контексте агента](../../openspec/changes/define-agent-platform/specs/agent-harness/spec.md#r-hrn-17)

### US-SBX-06 {#us-sbx-06}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** одним списком видеть и менять, к каким репозиториям и папкам проекта имеет доступ каждый агент, **чтобы** управлять доступами без кода.

**Точка входа:** Настройки проекта → доступы агентов

**Критерии приёмки:**

- [ ] Матрица агент × ресурс × право
- [ ] Изменение → со следующего запуска
- [ ] Ресурс удалён из каталога проекта → права на него сняты

**Требования:** [Манифест рабочего пространства](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md#r-run-17)

### US-SBX-07 {#us-sbx-07}

**Как** агент-ревьюер ([персона АгР](personas.md#агр-агент-ревьюер)), **я хочу** открыть результат исполнителя и вернуть с замечаниями, не изменяя его, **чтобы** ревью не портило чужой результат.

**Точка входа:** шаг ревью процесса

**Критерии приёмки:**

- [ ] Чтение артефактов исполнителя
- [ ] Замечания — в свою подпапку и комментарий
- [ ] Попытка записи в чужую подпапку → отказ

**Требования:** [Подключение рабочего пространства по манифесту](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md#r-sbx-14)
