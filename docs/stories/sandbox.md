## Истории

### US-SBX-01

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** получить чистую среду за доли секунды, **чтобы** запуск начинался сразу.

**Критерии приёмки:**

- [ ] Пул не пуст → старт без создания
- [ ] Пул пуст → создание на лету
- [ ] Нет ресурсов → ожидание в очереди

**Требования:** [Тёплый пул](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md) · [Поведение при отказах зависимостей](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md)

### US-SBX-02

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** дать агенту доступ только к нужным репозиториям, **чтобы** агент не трогал лишний код.

**Критерии приёмки:**

- [ ] Репозиторий из allowlist → клон
- [ ] Вне allowlist → отказ
- [ ] Push в main → отказ, только ветка агента

**Требования:** [Доступ к репозиториям](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md)

### US-SBX-03

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** чтобы агент не мог утечь данные в интернет, **чтобы** соблюдать безопасность.

**Критерии приёмки:**

- [ ] Запрещённый хост → блок и событие
- [ ] Прокси упал → весь трафик запрещён

**Требования:** [Сетевая изоляция](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md) · [Секреты](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md)

### US-SBX-04

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** получить файлы, созданные агентом, **чтобы** результат не терялся вместе с контейнером.

**Критерии приёмки:**

- [ ] Артефакт → вложение задачи до уничтожения среды
- [ ] Диск переполнен → ошибка агенту

**Требования:** [Эфемерный workspace](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md)

### US-SBX-05

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** получить результат предыдущего агента в своём рабочем пространстве, **чтобы** продолжить, а не начинать заново.

**Критерии приёмки:**

- [ ] Результат доступен на чтение
- [ ] Свои изменения не портят оригинал
- [ ] Нет доступа → понятная ошибка, а не пустота

**Требования:** ⚠️ нет — открытый вопрос, см. open-questions спек

### US-SBX-06

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** одним списком видеть и менять, к каким репозиториям и папкам проекта имеет доступ каждый агент, **чтобы** контролировать риски без кода.

**Критерии приёмки:**

- [ ] Список: агент → ресурс → право (чтение / запись)
- [ ] Изменение применяется со следующего запуска
- [ ] Попытка доступа вне списка → отказ и аудит

**Требования:** ⚠️ нет — открытый вопрос, см. open-questions спек

### US-SBX-07

**Как** агент-ревьюер ([персона АгР](personas.md#агр-агент-ревьюер)), **я хочу** открыть результат исполнителя и вернуть с замечаниями, не изменяя его, **чтобы** ревью было честным.

**Критерии приёмки:**

- [ ] Доступ только на чтение к артефакту
- [ ] Замечания — отдельным артефактом или комментарием

**Требования:** ⚠️ нет — открытый вопрос, см. open-questions спек
