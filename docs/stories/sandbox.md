| Шаг | Дорожка | Тип | Переходы |
|---|---|---|---|
| Нужна среда | Agent Runner | начало | → Пул не пуст? |

| Выдать контейнер | Sandbox | задача | → Исходящий запрос |
| Исходящий запрос | Sandbox | задача | → В allowlist? |

| Destroy, долив пула | Agent Runner | задача | → Среда удалена |
| Среда удалена | Agent Runner | конец | — |

## Истории

### US-SBX-01

**Как** агент (система), **я хочу** получить чистую среду за доли секунды, **чтобы** запуск начинался сразу.

**Критерии приёмки:**

- [ ] Пул не пуст → старт без создания
- [ ] Пул пуст → создание на лету
- [ ] Нет ресурсов → ожидание в очереди

**Требования:** [Тёплый пул](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md) · [Поведение при отказах зависимостей](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md)

### US-SBX-02

**Как** администратор платформы, **я хочу** дать агенту доступ только к нужным репозиториям, **чтобы** агент не трогал лишний код.

**Критерии приёмки:**

- [ ] Репозиторий из allowlist → клон
- [ ] Вне allowlist → отказ
- [ ] Push в main → отказ, только ветка агента

**Требования:** [Доступ к репозиториям](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md)

### US-SBX-03

**Как** эксплуатация, **я хочу** чтобы агент не мог утечь данные в интернет, **чтобы** соблюдать безопасность.

**Критерии приёмки:**

- [ ] Запрещённый хост → блок и событие
- [ ] Прокси упал → весь трафик запрещён

**Требования:** [Сетевая изоляция](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md) · [Секреты](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md)

### US-SBX-04

**Как** пользователь icplan, **я хочу** получить файлы, созданные агентом, **чтобы** результат не терялся вместе с контейнером.

**Критерии приёмки:**

- [ ] Артефакт → вложение задачи до уничтожения среды
- [ ] Диск переполнен → ошибка агенту

**Требования:** [Эфемерный workspace](../../openspec/changes/define-agent-platform/specs/agent-sandbox/spec.md)
