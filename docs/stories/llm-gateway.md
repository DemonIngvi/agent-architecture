## Истории

### US-LLM-01

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** сменить модель агента без изменения агента, **чтобы** быстро переключаться между моделями.

**Критерии приёмки:**

- [ ] Переназначение алиаса → новые вызовы в новую модель
- [ ] Неизвестный алиас → отказ

**Требования:** [Алиасы моделей](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md)

### US-LLM-02

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** разрабатывать без ключей провайдера, **чтобы** не платить за тесты.

**Критерии приёмки:**

- [ ] Алиас на mock → ответы сценария
- [ ] Нет сценария → ответ по умолчанию

**Требования:** [Mock-модель для разработки](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md)

### US-LLM-03

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** видеть стоимость работы агента по задаче, **чтобы** оценивать выгоду.

**Критерии приёмки:**

- [ ] Каждый вызов привязан к запуску и задаче
- [ ] Вызов без метаданных → отказ

**Требования:** [Атрибуция затрат](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md) · [Учёт токенов](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md)

### US-LLM-04

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** чтобы сбой провайдера не останавливал работу, **чтобы** агенты продолжали.

**Критерии приёмки:**

- [ ] Сбой → fallback-модель
- [ ] Резерв недоступен → ошибка, повтор в Harness

**Требования:** [Fallback](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md)
