## Истории

### US-LLM-01 {#us-llm-01}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** сменить модель агента без изменения агента, **чтобы** переходить на лучшие или дешёвые модели.

**Точка входа:** LiteLLM UI / Платформа

**Критерии приёмки:**

- [ ] Смена алиаса → все агенты алиаса на новой модели
- [ ] Новая модель недоступна → fallback
- [ ] Откат алиаса → со следующего вызова

**Требования:** [Алиасы моделей](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md) · [Смена модели агента](../../openspec/changes/define-agent-platform/specs/agent-registry/spec.md)

### US-LLM-02 {#us-llm-02}

**Как** тестировщик / qa ([персона QA](personas.md#qa-тестировщик-/-qa)), **я хочу** разрабатывать и тестировать без ключей провайдера, **чтобы** не тратить деньги на отладку.

**Точка входа:** алиас модели

**Критерии приёмки:**

- [ ] Алиас mock → скриптовые ответы и вызовы тулов
- [ ] Сценарий закончился → ответ по умолчанию
- [ ] Тот же агент на реальной модели — сменой алиаса

**Требования:** [Mock-модель для разработки](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md)

### US-LLM-03 {#us-llm-03}

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** видеть стоимость работы агента по задаче, **чтобы** понимать цену результата.

**Точка входа:** карточка задачи

**Критерии приёмки:**

- [ ] Токены и $ по задаче
- [ ] По запускам задачи
- [ ] Затраты недоступны → пометка, без ошибки

**Требования:** [Атрибуция затрат](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md) · [Затраты](../../openspec/changes/define-agent-platform/specs/observability/spec.md)

### US-LLM-04 {#us-llm-04}

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** чтобы сбой провайдера не останавливал работу, **чтобы** не терять задачи.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Провайдер недоступен → fallback-модель
- [ ] Fallback тоже недоступен → `failed` с причиной
- [ ] Rate limit → повтор с задержкой

**Требования:** [Fallback](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md) · [Несколько провайдеров](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md)

### US-LLM-05 {#us-llm-05}

**Как** владелец продукта ([персона ВП](personas.md#вп-владелец-продукта)), **я хочу** получать отчёт о затратах по агентам, проектам и моделям за период, **чтобы** планировать бюджет.

**Точка входа:** дашборд затрат

**Критерии приёмки:**

- [ ] Отчёт за период с разбивкой
- [ ] Экспорт в CSV
- [ ] Нет данных за период → пустой отчёт

**Требования:** [Атрибуция затрат](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md) · [Учёт токенов](../../openspec/changes/define-agent-platform/specs/llm-gateway/spec.md)
