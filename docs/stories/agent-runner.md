## Истории

### US-RUN-01

**Как** агент (система), **я хочу** забрать запуск из очереди и исполнить его в изолированной среде, **чтобы** задача ICPlan выполнялась агентом платформы.

**Критерии приёмки:**

- [ ] Запуск взят одним Runner
- [ ] Агент отключён → `agent_unavailable`
- [ ] ICPlan недоступен → опрос с backoff

**Требования:** [Запуск из очереди ICPlan](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md) · [Однократная выдача запуска](../../openspec/changes/add-icplan-integration/specs/icplan-integration/spec.md)

### US-RUN-02

**Как** эксплуатация, **я хочу** переключить платформу в последовательный режим, **чтобы** снизить нагрузку и траты.

**Критерии приёмки:**

- [ ] `sequential` → один запуск на платформу
- [ ] Агент `parallel: false` → всегда по одному

**Требования:** [Режим последовательно или параллельно](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md)

### US-RUN-03

**Как** эксплуатация, **я хочу** чтобы агенты не перегружали общую модель, **чтобы** не упираться в лимиты провайдера.

**Критерии приёмки:**

- [ ] Занят слот модели → запуск ждёт в `queued` с причиной
- [ ] Освобождение слота → старт по очереди

**Требования:** [Планирование по слотам](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md)

### US-RUN-04

**Как** эксплуатация, **я хочу** чтобы ожидание подтверждения не блокировало платформу, **чтобы** одна задача не тормозила остальные.

**Критерии приёмки:**

- [ ] Запуск ждёт approve → освобождает глобальный слот и слот модели
- [ ] Слот задачи остаётся занятым
- [ ] После решения → запуск снова ждёт слоты

**Требования:** [Слоты при ожидании подтверждения](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md)

### US-RUN-05

**Как** эксплуатация, **я хочу** чтобы падение Runner не теряло работу, **чтобы** запуски дошли до конца.

**Критерии приёмки:**

- [ ] Аренда истекла → запуск снова в очереди
- [ ] Слоты освобождены

**Требования:** [Общие слоты для нескольких Runner](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md) · [Поведение при отказах зависимостей](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md)
