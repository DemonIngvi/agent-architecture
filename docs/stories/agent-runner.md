## Истории

### US-RUN-01 {#us-run-01}

**Как** агент-исполнитель ([персона Аг](personas.md#аг-агент-исполнитель)), **я хочу** забрать запуск из очереди и исполнить его в изолированной среде, **чтобы** задача ICPlan выполнялась агентом платформы.

**Точка входа:** очередь ICPlan

**Участвует в цепочках ICPlan:** [US-ICP-01](icplan.md#us-icp-01), [US-ICP-08](icplan.md#us-icp-08), [US-ICP-09](icplan.md#us-icp-09), [US-ICP-19](icplan.md#us-icp-19), [US-ICP-04](icplan.md#us-icp-04), [US-ICP-16](icplan.md#us-icp-16), [US-ICP-17](icplan.md#us-icp-17), [US-ICP-22](icplan.md#us-icp-22), [US-ICP-27](icplan.md#us-icp-27), [US-ICP-07](icplan.md#us-icp-07)

**Критерии приёмки:**

- [ ] Запуск взят → создан sandbox, Harness получил задание
- [ ] Агент выключен или нет настроек → `agent_unavailable`, sandbox не создаётся
- [ ] Нет свободного слота → запуск ждёт в `queued`

**Требования:** [Запуск из очереди ICPlan](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md#r-run-01) · [Статусы запуска](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md#r-run-07) · [Возврат результата](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md#r-run-08)

### US-RUN-02 {#us-run-02}

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** переключить платформу в последовательный режим, **чтобы** разбирать проблемы по одному запуску.

**Точка входа:** конфиг деплоя

**Критерии приёмки:**

- [ ] `sequential` → одновременно один запуск
- [ ] Обратно `parallel` → параллельно по слотам
- [ ] Переключение при активных запусках → они доделываются, новые по новому режиму

**Требования:** [Режим последовательно или параллельно](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md#r-run-03)

### US-RUN-03 {#us-run-03}

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** чтобы агенты не перегружали общую модель, **чтобы** не упираться в лимиты провайдера.

**Точка входа:** конфиг деплоя

**Участвует в цепочках ICPlan:** [US-ICP-18](icplan.md#us-icp-18), [US-ICP-07](icplan.md#us-icp-07)

**Критерии приёмки:**

- [ ] Слоты модели заняты → запуск ждёт
- [ ] Освободился слот → следующий по порядку стартует
- [ ] Лимит модели изменён → действует для новых стартов

**Требования:** [Планирование по слотам](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md#r-run-02)

### US-RUN-04 {#us-run-04}

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** чтобы ожидание подтверждения не блокировало платформу, **чтобы** одна ждущая задача не держала всех.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Запуск ждёт approve → глобальный и модельный слоты освобождены
- [ ] Слот задачи держится — второго запуска по задаче нет
- [ ] Подтверждение пришло → запуск занимает слот заново

**Требования:** [Слоты при ожидании подтверждения](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md#r-run-04)

### US-RUN-05 {#us-run-05}

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** чтобы падение Runner не теряло работу, **чтобы** не перезапускать задачи вручную.

**Точка входа:** —

**Участвует в цепочках ICPlan:** [US-ICP-06](icplan.md#us-icp-06)

**Критерии приёмки:**

- [ ] Runner упал → аренда истекает, запуск снова в очереди
- [ ] Второй Runner → слоты общие, лимиты не превышаются
- [ ] Досылка событий после восстановления без дублей

**Требования:** [Общие слоты для нескольких Runner](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md#r-run-06) · [Поведение при отказах зависимостей](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md#r-run-14)

### US-RUN-06 {#us-run-06}

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** вывести Runner из работы для обновления, **чтобы** обновлять без потери запусков.

**Точка входа:** команда эксплуатации / rolling update

**Критерии приёмки:**

- [ ] Режим «не брать новые» → активные доделываются, новые не берутся
- [ ] Все активные завершены → Runner можно остановить
- [ ] Таймаут вывода → оставшиеся запуски возвращаются в очередь

**Требования:** [Развёртывание](../../openspec/changes/define-agent-platform/specs/agent-runner/spec.md#r-run-16)
