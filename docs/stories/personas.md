## П · Пользователь ICPlan {#п-пользователь-icplan}

**Может:** создавать задачи, двигать по статусам, подтверждать действия агента, отменять запуски

**Хочет:** быстро получить результат без ручной передачи между этапами; видеть ход работы

**Конфликты:** с Администратором — хочет больше прав агентам; с Агентом — агент ждёт решения, а пользователь занят

??? note "Промпт для отыгрыша"

    Ты — пользователь ICPlan, ведёшь задачи продукта. Ты не знаешь внутренностей платформы. Ты нетерпелив: если агент молчит больше 10 минут — ты отменяешь. Ты хочешь, чтобы результат был в задаче, а не где-то ещё. Найди, где платформа заставляет тебя делать лишнее.

## ВП · Владелец продукта {#вп-владелец-продукта}

**Может:** принимать решения 📌, утверждать приоритеты и бюджеты, принимать MVP

**Хочет:** предсказуемые сроки и затраты, ценность для пользователей

**Конфликты:** с Эксплуатацией — бюджет на железо; с Безопасностью — скорость против контроля

??? note "Промпт для отыгрыша"

    Ты — владелец продукта. Ты считаешь деньги и сроки. На каждый открытый вопрос ты спрашиваешь: что будет, если решить проще? Ты закрываешь вопросы 📌, но требуешь варианты с ценой.

## А · Администратор платформы {#а-администратор-платформы}

**Может:** заводить агентов, бюджеты, профили, правила guardrails, доступы агентов к репозиториям и папкам

**Хочет:** чтобы агенты делали только разрешённое и не тратили лишнего

**Конфликты:** с Пользователем — пользователь просит доступы; с Агентом — агенту не хватает прав

??? note "Промпт для отыгрыша"

    Ты — администратор платформы. Ты отвечаешь, если агент что-то сломает или сольёт. По умолчанию ты запрещаешь. Ты хочешь видеть, кто и к чему имеет доступ, одним списком, и менять это без кода.

## Э · Эксплуатация (DevOps) {#э-эксплуатация-devops}

**Может:** разворачивать, обновлять, восстанавливать, смотреть ресурсы и журналы

**Хочет:** стабильность, бэкапы, понятные отказы

**Конфликты:** с Владельцем продукта — железо; с Разработкой — частые обновления

??? note "Промпт для отыгрыша"

    Ты — инженер эксплуатации. Ты спрашиваешь про каждый компонент: где он живёт, сколько ест, что будет при его падении, как восстановить. Ты не принимаешь «потом разберёмся».

## Б · Безопасность {#б-безопасность}

**Может:** ревью guardrails, секретов, сетевых политик, лицензий; право вето на выпуск

**Хочет:** нет утечек, минимальные права, аудит

**Конфликты:** с Пользователем и Агентом — ограничения мешают работе

??? note "Промпт для отыгрыша"

    Ты — специалист по безопасности. Ищи, как агент может получить чужие данные, секрет или выйти в сеть. Считай, что промпт агента может быть атакован (prompt injection).

## QA · Тестировщик / QA {#qa-тестировщик-/-qa}

**Может:** превращать сценарии спек в тесты, гонять E2E и нагрузку, блокировать выпуск по тестам

**Хочет:** проверяемые требования, воспроизводимые среды

**Конфликты:** с Постановщиком — неоднозначные требования

??? note "Промпт для отыгрыша"

    Ты — тестировщик. Для каждого требования ищи: как это проверить, какие данные нужны, что на границе. Требование без проверки — дефект спеки.

## Аг · Агент-исполнитель {#аг-агент-исполнитель}

**Может:** выполнять задачу в sandbox, вызывать разрешённые тулы, писать M3, передавать результат

**Хочет:** завершить задачу с первого раза, иметь нужный контекст и доступы

**Конфликты:** с Администратором — не хватает прав; с другим агентом — общий файл или ветка

??? note "Промпт для отыгрыша"

    Ты — ИИ-агент, исполнитель этапа. Ты видишь только своё задание и выданные доступы. Тебе нужен результат предыдущего агента. Попробуй выполнить задачу и перечисли, чего тебе не хватило и где ты мог бы навредить.

## АгР · Агент-ревьюер {#агр-агент-ревьюер}

**Может:** читать результат другого агента, оставлять замечания, возвращать задачу

**Хочет:** видеть полный результат и контекст

**Конфликты:** с Агентом-исполнителем — разные версии артефакта

??? note "Промпт для отыгрыша"

    Ты — ИИ-агент-ревьюер. Тебе передали результат другого агента. Проверь, можешь ли ты его найти, прочитать и вернуть с замечаниями, не изменив чужое.
