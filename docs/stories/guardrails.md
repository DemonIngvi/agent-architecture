## Истории

### US-GRD-01 {#us-grd-01}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** включать и выключать проверки по точкам, **чтобы** подстраивать строгость под среду.

**Точка входа:** конфиг деплоя

**Критерии приёмки:**

- [ ] G1–G4 включаются отдельно
- [ ] Выключение G2 в prod → предупреждение
- [ ] Изменение → после перезапуска модуля

**Требования:** [Включение и выключение точек](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md)

### US-GRD-02 {#us-grd-02}

**Как** пользователь icplan ([персона П](personas.md#п-пользователь-icplan)), **я хочу** понимать, почему агенту отказали, **чтобы** исправить задачу или попросить доступ.

**Точка входа:** таймлайн задачи

**Критерии приёмки:**

- [ ] Отказ → причина и правило в таймлайне задачи
- [ ] Отказ по бюджету → «бюджет исчерпан»
- [ ] Отказ OPA недоступен → «проверка недоступна, действие запрещено»

**Требования:** [Аудит срабатываний](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md) · [Движок решений для G1 и G2](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md)

### US-GRD-03 {#us-grd-03}

**Как** владелец продукта ([персона ВП](personas.md#вп-владелец-продукта)), **я хочу** чтобы траты не выходили за бюджет, **чтобы** контролировать расходы.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Бюджет агента исчерпан → запуски отклоняются
- [ ] Бюджет проекта ограничивает агентов
- [ ] Аномальный расход → стоп и уведомление

**Требования:** [Иерархия бюджетов токенов и денег](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md) · [Аномальный расход](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md)

### US-GRD-04 {#us-grd-04}

**Как** эксплуатация (devops) ([персона Э](personas.md#э-эксплуатация-devops)), **я хочу** мгновенно остановить агента или всю платформу, **чтобы** остановить инцидент.

**Точка входа:** команда эксплуатации / Настройки

**Критерии приёмки:**

- [ ] Стоп агента → его запуски отменены, новые отклоняются
- [ ] Стоп всех → все запуски отменены
- [ ] Снятие стопа → работа возобновляется

**Требования:** [Аварийная остановка](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md)

### US-GRD-05 {#us-grd-05}

**Как** безопасность ([персона Б](personas.md#б-безопасность)), **я хочу** просматривать журнал срабатываний guardrails, **чтобы** находить опасные попытки агентов.

**Точка входа:** Настройки → журнал guardrails

**Критерии приёмки:**

- [ ] Журнал: агент, задача, точка, правило, решение
- [ ] Фильтр по агенту, точке, периоду
- [ ] Записи хранятся по политике хранения

**Требования:** [Аудит срабатываний](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md)

### US-GRD-06 {#us-grd-06}

**Как** администратор платформы ([персона А](personas.md#а-администратор-платформы)), **я хочу** задать правила: какие тулы требуют подтверждения, **чтобы** агент спрашивал там, где риск.

**Точка входа:** агент → правила

**Критерии приёмки:**

- [ ] Тул в списке approval → пауза на подтверждение
- [ ] Тул вне allowlist → отказ
- [ ] Правило с ошибкой → не применяется, прежнее действует

**Требования:** [G2 Action](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md) · [Единый источник правил](../../openspec/changes/define-agent-platform/specs/guardrails/spec.md)
