## Схема

```
                         Пользователи (браузер)        Агенты внешних CLI
                                  │ HTTPS (I21)               │ HTTPS /mcp
┌─ Узел k3s · 8 vCPU / 32 ГБ / 400 ГБ ─────────────────────────────────────────┐
│ ┌──────────────────────────────────────────────────────────────────────────┐ │
│ │ Traefik ingress ~ · TLS (ACME) · маршруты: web, api, /mcp · админки — нет │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
│                     │ Service (ClusterIP) — балансировка по репликам           │
│ ┌─ itsaplan-core ─────────────────────────────────────────────────────────┐   │
│ │ web ×1–2 ✓   api ×2 ✓ (MCP, Platform module ·)   worker ×1 ✓   bot ×1 ✓ │   │
│ └─────────────────────────────────────────────────────────────────────────┘   │
│ ┌─ itsaplan-agents ───────────────────────────────────────────────────────┐   │
│ │ Agent Runner ×1 ·   LiteLLM ×2 ~   OPA ×2 ~   Memory API ×1 ·          │   │
│ │ egress-прокси ×1 ·  запуски: Pod на запуск + тёплый пул ·               │   │
│ └─────────────────────────────────────────────────────────────────────────┘   │
│                     │ PostgreSQL через PgBouncer (I22) · S3 API (I19)          │
│ ┌─ itsaplan-data ─────────────────────────────────────────────────────────┐   │
│ │ PgBouncer · (transaction, ≤30)  ─▶  PostgreSQL 17 + pgvector ~           │   │
│ │                                     (CloudNativePG ·; БД itsaplan, litellm)│ │
│ │ RustFS ~ (S3: planner-attachments)                                        │   │
│ └─────────────────────────────────────────────────────────────────────────┘   │
│ ┌─ itsaplan-platform (бэклог) ──────────────────────────────────────────────┐ │
│ │ Prometheus · Grafana · Loki · Gitea                                       │ │
│ └───────────────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────┘
                                  │ базовые копии + WAL, копия RustFS
                         S3-хранилище вне узла ·
```

## Блоки

| Блок | Задача | Статус |
|---|---|---|
| Traefik | Вход по HTTPS, TLS, маршруты | ⚠️ проверен локально (AI-агент 7.12) |
| Service (ClusterIP) | Балансировка по репликам | ✅ средство k8s |
| PgBouncer | Пул соединений Postgres | ⬜ не начато |
| PostgreSQL 17 + pgvector | Данные ICPlan, платформы, LiteLLM | ⚠️ есть в compose; CloudNativePG — не начато |
| RustFS | S3 для вложений и копий | ⚠️ есть в compose |
| S3 вне узла | Резервные копии | ⬜ не начато |
| NetworkPolicy | Изоляция зон | ⬜ не начато |

## Ёмкость (из R&D)

| Сервис | Реплики | RAM | CPU |
|---|---|---|---|
| k3s | — | 0.7 ГБ | 0.2 |
| PostgreSQL 17 + pgvector | 1 | 2 ГБ | 1 |
| web / api / worker / bot | 1–2 / 2 / 1 / 1 | ~1.5 ГБ | ~0.7 |
| LiteLLM | 2 | 1.6 ГБ | 0.6 |
| OPA | 2 | 0.2 ГБ | 0.1 |
| RustFS | 1 | 0.5 ГБ | 0.2 |
| Запуски агентов | до 10 обычных или 4–5 «coder» | 0.3 / 1–2 ГБ каждый | 0.2 / 1–2 |
