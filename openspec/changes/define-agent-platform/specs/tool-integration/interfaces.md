# tool-integration — конфигурация, данные, интерфейсы, отказы

← [spec.md](spec.md) · [схема](architecture.md) · [трассировка](traceability.md) · [правила](../../../../../docs/rules/spec-criteria.md)

## Уровни конфигурации

| Уровень | Что | Где хранится | Область |
|---|---|---|---|
| L0 | Конфиг деплоя | S9 | платформа целиком: адреса, переключатели G1–G4, режим планирования, потолки лимитов |
| L1 | Platform module | S2 | агент: бюджеты, профили, данные guardrails, флаги планирования |
| L2 | Определение агента | S1 (+ YAML импорт) | агент: модель, инструкция, тулы, навыки, MCP, лимиты запуска |
| L3 | Запуск | задача ICPlan / `Run` | версия агента, критерии приёмки, задание |

Правило: значение берётся с самого конкретного уровня (L3 → L0), но не выше потолка L0.

## Параметры модуля

Значения и границы пересматриваются по статистике запусков (3.9) и нагрузочному тесту (4.8); правило — [виды спек, таблица параметров](../../../../../docs/rules/spec-kinds.md#params).

| Параметр | Что задаёт | Уровень | Хранилище | По умолчанию | Почему так по умолчанию | Мин | Макс | На что опираться при выборе |
|---|---|---|---|---|---|---|---|---|
| `servers` | Подключённые MCP-серверы | L2 | S1 | itsaplan-core | агенту нужен ICPlan | itsaplan-core | каталог серверов | только серверы, нужные агенту |
| `tools` | Allowlist тулов сервера | L2 | S1 | минимальный (чтение задачи, комментарий) | наименьшие права | пусто | все тулы сервера | тулы, без которых агент не сделает работу |
| `timeout_s` | Таймаут вызова | L2 | S1 | 30 | REST ICPlan: 10 с × 3 | 5 | 300 | долгие тулы — асинхронно, не увеличением таймаута |
| `max_result_kb` | Обрезка ответа тула | L0 | S9 | 64 | ≈ 16 тыс. токенов ≈ 8% окна 200 тыс. | 8 | 256 | 256 КБ ≈ 64 тыс. токенов — треть окна |
| `auth.secret_ref` | Ссылка на секрет | L2 | S1 | — (обязательный) | секрет не хранится в настройках | ссылка на Secret | ссылка на Secret | только ссылка, не значение |

## Отказы (FMEA)

| Отказ | Обнаружение | Поведение | Восстановление |
|---|---|---|---|
| MCP-сервер недоступен | таймаут | ошибка тула агенту | circuit breaker |
| Секрет MCP не задан | ошибка авторизации | тулы сервера недоступны агенту, предупреждение | задать секрет |
| Сервер изменил набор тулов | сверка `tools/list` | новые тулы не видны без allowlist | обновление allowlist |
