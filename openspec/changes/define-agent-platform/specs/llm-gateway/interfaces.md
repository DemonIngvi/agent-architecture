← [spec.md](spec.md) · [схема](architecture.md) · [трассировка](traceability.md) · [правила](../../../../../docs/rules/spec-criteria.md)

## Уровни конфигурации

| Уровень | Что | Где хранится | Область |
|---|---|---|---|
| L0 | Конфиг деплоя | S9 | платформа целиком: адреса, переключатели G1–G4, режим планирования, потолки лимитов |
| L1 | Platform module | S2 | агент: бюджеты, профили, данные guardrails, флаги планирования |
| L2 | Определение агента | S1 (+ YAML импорт) | агент: модель, инструкция, тулы, навыки, MCP, лимиты запуска |
| L3 | Запуск | задача ICPlan / `Run` | версия агента, критерии приёмки, задание |

Правило: значение берётся с самого конкретного уровня (L3 → L0), но не выше потолка L0.

## Параметры модуля

| Параметр | Что задаёт | Уровень | Хранилище | По умолчанию |
|---|---|---|---|---|
| `model_list` | Алиасы → модели | L0 | S9 (`litellm config.yaml`) | team-default → mock |
| `fallbacks` | Резервные модели | L0 | S9 (`litellm config.yaml`) | нет |
| `key.max_budget` | Бюджет virtual key | L1 | S6 | из Platform module |
| `key.rpm / tpm` | Запросы и токены в минуту | L1 | S6 | 60 / — |
| `guardrails (G4)` | PII, injection, модерация | L0 | S9 (`litellm config.yaml`) | выкл |

## Хранилища данных

| ID | Хранилище | Что хранит | Владелец | Резервирование / срок |
|---|---|---|---|---|
| S6 | PostgreSQL 17 (тот же кластер), БД `litellm` | virtual keys, бюджеты, журнал затрат | LiteLLM | журнал затрат — по политике LiteLLM |
| S9 | Конфиг деплоя: `values.yaml` (git, без секретов) + Secret / `.env` (вне git) | параметры платформы, адреса, переключатели guardrails, секреты | эксплуатация | версии в git; секреты — вне git |

## Интерфейсы обмена

| ID | От → к | Протокол | Формат | Аутентификация | Режим | Таймаут | Повтор | Идемпотентность |
|---|---|---|---|---|---|---|---|---|
| I8 | Harness → LiteLLM | HTTP, OpenAI Chat Completions, SSE-стрим | JSON + `metadata.run_id` | Bearer virtual key (подставляет egress-прокси) | синхронно / стрим | 120 с | 2 раза с backoff | нет — повтор = новые затраты |

| I22 | Сервисы → PgBouncer → Postgres | протокол PostgreSQL | SQL | логин / пароль из Secret, роль на схему | синхронно | 5 с на запрос | 1 раз (только чтение) | — |

## Нагрузка и развёртывание

| | |
|---|---|
| **Нагрузка** (гипотеза, [R&D](../../../../../docs/rnd/load-profile.md)) | 0.4–1 RPS, ~55 тыс. токенов/мин в пике; ответ модели 5–20 с, стрим |
| **Развёртывание** ([R&D](../../../../../docs/rnd/kubernetes-runtime.md)) | LiteLLM — Deployment `litellm` в `itsaplan-agents`, 2 реплики за Service ClusterIP; БД `litellm` через PgBouncer; админка без ingress |

Детали форматов — [потоки](../../../../../docs/flows/llm-gateway.md).

## Отказы (FMEA)

| Отказ | Обнаружение | Поведение | Восстановление |
|---|---|---|---|
| Провайдер недоступен | ошибки I13 | fallback-модель; если нет — ошибка вызова | переключение алиаса |
| БД `litellm` недоступна | ошибки I14 | проверка бюджетов невозможна — вызовы отклоняются | восстановление БД |
| Нет ключа провайдера | ошибка авторизации провайдера | алиас недоступен | добавление ключа в Secret |
| LiteLLM упал | health-check | вызовы Harness получают ошибку, circuit breaker | реплики, перезапуск |
