## Уровни конфигурации

| Уровень | Что | Где хранится | Область |
|---|---|---|---|
| L0 | Конфиг деплоя | S9 | платформа целиком: адреса, переключатели G1–G4, режим планирования, потолки лимитов |
| L1 | Platform module | S2 | агент: бюджеты, профили, данные guardrails, флаги планирования |
| L2 | Определение агента | S1 (+ YAML импорт) | агент: модель, инструкция, тулы, навыки, MCP, лимиты запуска |
| L3 | Запуск | задача ICPlan / `Run` | версия агента, критерии приёмки, задание |

Правило: значение берётся с самого конкретного уровня (L3 → L0), но не выше потолка L0.

## Параметры модуля

| Параметр | Что задаёт | Уровень | Хранилище | По умолчанию |
|---|---|---|---|---|
| `read` | Какие уровни читать | L1 | S2 | M2, M3, M5, M6 |
| `write` | Какие уровни агент пишет | L1 | S2 | M3 |
| `m2_last_runs` | Сколько прошлых запусков в контекст | L1 | S2 | 3 |
| `retention` | Сроки хранения | L1 | S2 | M1 30 д, M2 180 д, M3 до закрытия задачи |
| `scope` | Область записи: задача, агент, проект, команда | L1 | S2 | задача |

## Хранилища данных

| ID | Хранилище | Что хранит | Владелец | Резервирование / срок |
|---|---|---|---|---|
| S1 | PostgreSQL 17 (CloudNativePG), БД `itsaplan`, схема `public` | задачи, агенты, `agent_run`, `issue_activity`, статусы, документы | ICPlan | базовые копии + WAL в S3 вне узла |
| S4 | Postgres ICPlan, схема `platform`, таблица `memory_m3`; позже pgvector для M4 | состояние задач (M3); факты (M4) | Memory | M3 — до закрытия задачи |

## Интерфейсы обмена

| ID | От → к | Протокол | Формат | Аутентификация | Режим | Таймаут | Повтор | Идемпотентность |
|---|---|---|---|---|---|---|---|---|
| I11 | Harness → Memory API | HTTP REST | JSON `M3Record`, контекст | токен запуска | синхронно | 2 с | 2 раза | запись M3 — upsert по (задача, область) |
| I2 | Agent Runner → ICPlan (шаги, итог) | HTTP REST | JSON-пакеты `RunEvent` с `seq`, `RunResult` | Bearer API-ключ агента | асинхронно | 10 с | повтор с дедупликацией по (run_id, seq) | да, по (run_id, seq) |

## Нагрузка и развёртывание

| | |
|---|---|
| **Нагрузка** (гипотеза, [R&D](../../../../../docs/rnd/load-profile.md)) | ~1 RPS чтения и записи; M3 до 10 КБ на задачу; p95 < 200 мс |
| **Развёртывание** ([R&D](../../../../../docs/rnd/kubernetes-runtime.md)) | Memory API — Deployment в `itsaplan-agents`, 1–2 реплики, Service ClusterIP; данные — Postgres через PgBouncer |

Детали форматов — [потоки](../../../../../docs/flows/memory.md).

## Отказы (FMEA)

| Отказ | Обнаружение | Поведение | Восстановление |
|---|---|---|---|
| БД недоступна | ошибка Memory API | чтение — пустой контекст с предупреждением; запись — повтор | восстановление БД |
| Конфликт записи M3 | две записи одной области | последняя версия, прежняя в истории | — |
| Профиль памяти не задан | нет профиля у агента | используется профиль по умолчанию из L0 | администратор задаёт профиль |
