# control-plane — конфигурация, данные, интерфейсы, отказы

← [spec.md](spec.md) · [схема](architecture.md) · [трассировка](traceability.md) · [правила](../../../../../docs/rules/spec-criteria.md)

## Уровни конфигурации

| Уровень | Что | Где хранится | Область |
|---|---|---|---|
| L0 | Конфиг деплоя | S9 | платформа целиком: адреса, переключатели G1–G4, режим планирования, потолки лимитов |
| L1 | Platform module | S2 | агент: бюджеты, профили, данные guardrails, флаги планирования |
| L2 | Определение агента | S1 (+ YAML импорт) | агент: модель, инструкция, тулы, навыки, MCP, лимиты запуска |
| L3 | Запуск | задача ICPlan / `Run` | версия агента, критерии приёмки, задание |

Правило: значение берётся с самого конкретного уровня (L3 → L0), но не выше потолка L0.

## Параметры модуля

| Параметр | Что задаёт | Уровень | Хранилище | По умолчанию |
|---|---|---|---|---|
| `model_alias` | Алиас модели агента | L1 | S2 | team-default |
| `fallback` | Резервная модель | L0 | S9 | нет |
| `budget.daily_usd` | Дневной бюджет агента | L1 | S2 | 5 $ |
| `budget.per_run_tokens` | Токены на один запуск | L1 | S2 | 200 000 |
| `rate_limit` | Запросов в минуту | L1 | S2 | 60 |
| `limits.max_steps` | Шагов цикла на запуск | L1 | S2 | 30 |
| `limits.timeout_s` | Время запуска | L1 | S2 | 1800 |
| `concurrency` | Параллельных запусков агента | L1 | S2 | 1 |
| `sandbox_profile` | Профиль среды: образ, CPU, RAM, диск | L1 | S2 | light |
| `sandbox.egress_allow` | Разрешённые хосты | L1 | S2 | только платформа |
| `sandbox.pool.size` | Готовых контейнеров | L1 | S2 | 2 |
| `memory_profile.read` | Какие уровни памяти читать | L1 | S2 | M2, M3, M5, M6 |
| `memory_profile.write` | Какие уровни агент пишет | L1 | S2 | M3 |
| `memory.m2_last_runs` | Сколько прошлых запусков в контекст | L1 | S2 | 3 |
| `memory.retention` | Сроки хранения уровней | L1 | S2 | M1 30 д, M2 180 д |
| `guardrails.tools_allow` | Разрешённые тулы | L1 | S2 | из определения |
| `guardrails.approval` | Тулы с подтверждением человека | L1 | S2 | запись в задачу, push |
| `guardrails.approval_timeout` | Сколько ждать подтверждения | L1 | S2 | 24 ч |
| `repos` | Репозитории, доступ, префикс ветки | L1 | S2 | нет |
| `version` | Версия определения агента | L1 | S2 | последняя |

## Хранилища данных

| ID | Хранилище | Что хранит | Владелец | Резервирование / срок |
|---|---|---|---|---|
| S2 | Postgres ICPlan, схема `platform` | настройки агентов, версии, профили sandbox и памяти, данные guardrails, параметры планирования | Platform module | вместе с S1 |
| S6 | Postgres, отдельная БД `litellm` | virtual keys, бюджеты, журнал затрат | LiteLLM | журнал затрат — по политике LiteLLM |
| S9 | Конфиг деплоя: `values.yaml` (git, без секретов) + Secret / `.env` (вне git) | параметры платформы, адреса, переключатели guardrails, секреты | эксплуатация | версии в git; секреты — вне git |

## Отказы (FMEA)

| Отказ | Обнаружение | Поведение | Восстановление |
|---|---|---|---|
| LiteLLM admin API недоступен | ошибка I15 | изменение помечено «не применено», повтор | автоповтор, предупреждение |
| OPA не забрал bundle | версия bundle в OPA устарела | решения по старым данным, предупреждение администратору | повтор опроса |
| Рассинхронизация настроек | сверка S2 и S6 | предупреждение, новые запуски используют S2 | повторная раздача |
