## Схема

```
┌──────────────────────┐  ┌──────────────────────┐  ┌──────────────────────┐
│ Rego в git ·         │  │ ↗ Данные правил      │  │ Конфиг деплоя ·      │
└──────────────────────┘  └──────────────────────┘  └──────────────────────┘
                                     ↓
┌──────────────────────────────────────────────────────────────────────────┐
│ OPA ~                                                                    │
└──────────────────────────────────────────────────────────────────────────┘
                      ↓ решения allow / deny / confirm
┌─ Точки применения ───────────────────────────────────────────────────────┐
│ ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌────────────────┐ │
│ │ ↗ G1 Admissi │  │ ↗ G2 Action  │  │ ↗ G3 Isolati │  │ ↗ G4 LLM [G4]  │ │
│ └──────────────┘  └──────────────┘  └──────────────┘  └────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
                                     ↓
┌──────────────────────────────────────────────────────────────────────────┐
│ ↗ Аудит                                                                  │
└──────────────────────────────────────────────────────────────────────────┘
```

## Блоки

| Блок | Задача | Статус |
|---|---|---|
| Rego в git | логика правил, opa test | ⬜ не начато |
| Конфиг деплоя | guardrails.gN.enabled, on_engine_error | ⬜ не начато |
| OPA | движок решений G1 / G2 | ⚠️ частично |

## Расширения и настройка

```
engine                             → opa или none
g1.enabled … g4.enabled            → Какие риски закрыты
on_engine_error                    → deny — безопаснее, allow — доступнее
tools_allow / approval             → Что разрешено и что с подтверждением
Rego-правила                       → Строгость политики
loop.repeat_calls                  → Не тратит токены на зацикливание
loop.no_progress_steps             → Останавливает «топтание на месте»
limits.idle_s                      → Зависшие запуски освобождают слот
```

## Плюсы / минусы

| ➕ | ➖ |
|---|---|
| Безопасность настраивается и проверяется, а не размазана по коду | Rego нужно изучить |
| Понятно, почему агенту отказали (аудит) | Ещё один сервис; при недоступности — отказ (fail-closed) |
| Опасные действия ждут человека |  |
