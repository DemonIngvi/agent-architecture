## Уровни конфигурации

| Уровень | Что | Где хранится | Область |
|---|---|---|---|
| L0 | Конфиг деплоя | S9 | платформа целиком: адреса, переключатели G1–G4, режим планирования, потолки лимитов |
| L1 | Platform module | S2 | агент: бюджеты, профили, данные guardrails, флаги планирования |
| L2 | Определение агента | S1 (+ YAML импорт) | агент: модель, инструкция, тулы, навыки, MCP, лимиты запуска |
| L3 | Запуск | задача ICPlan / `Run` | версия агента, критерии приёмки, задание |

Правило: значение берётся с самого конкретного уровня (L3 → L0), но не выше потолка L0.

## Параметры модуля

| Параметр | Что задаёт | Уровень | Хранилище | По умолчанию |
|---|---|---|---|---|
| `engine` | Движок решений | L0 | S9 | opa |
| `g1.enabled … g4.enabled` | Включение точек | L0 | S9 | g1–g3 вкл, g4 выкл |
| `on_engine_error` | Поведение при недоступности OPA | L0 | S9 | deny |
| `tools_allow / approval` | Данные правил агента | L1 | S2 | из агента |
| `autonomy_level` | Уровень автономии R0–R5 (политика подтверждений) | L1 | S2 | R2 |
| `Rego-правила` | Логика проверок | L0 | S8 | allowlist + approval |
| `loop.repeat_calls` | Повторов одинакового вызова до стопа | L0 | S9 | 3 |
| `loop.no_progress_steps` | Шагов без прогресса до стопа | L0 | S9 | 8 |
| `limits.idle_s` | Простой без событий | L1 | S2 | 300 |
| `budget.run / agent_day / project_month` | Иерархия бюджетов | L1 | S2 | 1 $ / 5 $ / задаётся |
| `anomaly.step_x_median` | Порог скачка расхода шага | L0 | S9 | 5 |
| `circuit.max_errors` | Ошибок подряд до стопа | L0 | S9 | 3 |
| `kill_switch` | Аварийная остановка агента или платформы | L1 | S2 | выкл |

## Хранилища данных

| ID | Хранилище | Что хранит | Владелец | Резервирование / срок |
|---|---|---|---|---|
| S2 | Postgres ICPlan, схема `platform` | настройки агентов, версии, профили sandbox и памяти, данные guardrails, параметры планирования | Platform module | вместе с S1 |
| S8 | git: репозитории продукта; репозиторий политик Rego | код агентов (ветки, PR); правила guardrails | git-провайдер | история git |
| S9 | Конфиг деплоя: `values.yaml` (git, без секретов) + Secret / `.env` (вне git) | параметры платформы, адреса, переключатели guardrails, секреты | эксплуатация | версии в git; секреты — вне git |
| S11 | OPA в памяти (bundle) | правила и данные для решений | Guardrails | не источник правды — пересобирается из S2 и S8 |

## Интерфейсы обмена

| ID | От → к | Протокол | Формат | Аутентификация | Режим | Таймаут | Повтор | Идемпотентность |
|---|---|---|---|---|---|---|---|---|
| I5 | Agent Runner → OPA (G1) | HTTP REST `POST /v1/data/agent/g1` | JSON `PolicyInput` / `PolicyDecision` | внутренняя сеть (mTLS — позже) | синхронно | 200 мс | нет → `on_engine_error` | чтение |
| I10 | Harness → OPA (G2) | HTTP REST `POST /v1/data/agent/g2` | JSON `PolicyInput` / `PolicyDecision` | внутренняя сеть | синхронно | 200 мс | нет → `on_engine_error` | чтение |
| I16 | Platform module + git (Rego) → OPA | OPA bundles API, HTTP pull | tar.gz bundle | токен bundle-сервера | опрос 30 с | 10 с | встроенный в OPA | да |
| I8 | Harness → LiteLLM | HTTP, OpenAI Chat Completions, SSE-стрим | JSON + `metadata.run_id` | Bearer virtual key (подставляет egress-прокси) | синхронно / стрим | 120 с | 2 раза с backoff | нет — повтор = новые затраты |

## Отказы (FMEA)

| Отказ | Обнаружение | Поведение | Восстановление |
|---|---|---|---|
| OPA недоступен | таймаут I5 / I10 | по `on_engine_error`: deny (по умолчанию) или allow с пометкой | восстановление OPA |
| Битый Rego | `opa test` / ошибка загрузки bundle | OPA остаётся на прежнем bundle | исправление в git |
| Точка выключена | конфиг L0 | проверка не выполняется, запись в лог старта | включение конфигом |
| Нет данных правил агента | пустые данные | deny всех тулов кроме явно разрешённых в L0 | заполнение в Platform module |
