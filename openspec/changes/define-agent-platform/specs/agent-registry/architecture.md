# agent-registry — схема

← [spec.md](spec.md)

Схема в формате [FORMAT.md](../../../../../FORMAT.md). Легенда: ✓ есть · ~ частично · · не начато · ↗ соседний компонент.

## Схема

```
┌───────────────────────────────────┐  ┌───────────────────────────────────┐
│ ↗ Control Plane UI                │  │ ↗ Platform module                 │
└───────────────────────────────────┘  └───────────────────────────────────┘
                                ↓ сохранение
┌─ Registry (БД ICPlan) ───────────────────────────────────────────────────┐
│ ┌────────────────────┐  ┌────────────────────┐  ┌──────────────────────┐ │
│ │ Агенты ✓           │  │ Тулы и навыки ✓    │  │ MCP-серверы ✓        │ │
│ └────────────────────┘  └────────────────────┘  └──────────────────────┘ │
│ ┌────────────────────┐  ┌────────────────────┐  ┌──────────────────────┐ │
│ │ Ключи провайдеров  │  │ Версии агента ·    │  │ Экспорт / импорт YAM │ │
│ └────────────────────┘  └────────────────────┘  └──────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
                            ↓ определение агента
┌───────────────────────────────────┐  ┌───────────────────────────────────┐
│ ↗ Agent Runner                    │  │ ↗ Harness                         │
└───────────────────────────────────┘  └───────────────────────────────────┘
```

## Расширения и настройка

```
Статусы доски                      → Какие этапы проходит задача
Агент-делегат статуса              → Задача сама уходит нужному агенту
Агент-делегат типа                 → Разные типы — разные исполнители
Действия                           → Автоматизация по меткам и полям
Модель агента                      → Качество и цена ответов
Инструкция агента                  → Что и как делает агент
Тулы и навыки                      → Набор доступных действий
MCP проекта                        → Без него агент не меняет задачи
```

## Плюсы / минусы

| ➕ | ➖ |
|---|---|
| Не пишем трекер и UI с нуля — экономия месяцев разработки | AGPL-3.0: если доработанный форк доступен пользователям по сети, исходники изменений обязаны быть им доступны — наши доработки фактически открытые |
| Процесс (статусы, переходы) настраивает сам пользователь, без кода | Малое сообщество (923★) — риск поддержки; upstream может уйти в сторону |
| Агенты видны как участники команды: исполнитель, комментарии, история | Слияния с upstream усложняются по мере доработок |
