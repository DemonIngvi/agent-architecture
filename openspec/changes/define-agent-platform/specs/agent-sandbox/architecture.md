# agent-sandbox — схема

← [spec.md](spec.md)

Схема в формате [FORMAT.md](../../../../../FORMAT.md). Легенда: ✓ есть · ~ частично · · не начато · ↗ соседний компонент.

## Схема

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ↗ Agent Runner                                                           │
└──────────────────────────────────────────────────────────────────────────┘
                                     ↓
┌───────────────────────────────────┐  ┌───────────────────────────────────┐
│ Тёплый пул ·                      │  │ SandboxProvider ·                 │
└───────────────────────────────────┘  └───────────────────────────────────┘
                       ↓ один контейнер = один запуск
┌─ Контейнер запуска [G3] ─────────────────────────────────────────────────┐
│ ┌─────────────────────────────────┐  ┌─────────────────────────────────┐ │
│ │ ↗ Harness                       │  │ /workspace ·                    │ │
│ └─────────────────────────────────┘  └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐  ┌─────────────────────────────────┐ │
│ │ Профиль ·                       │  │ Credential helper ·             │ │
│ └─────────────────────────────────┘  └─────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
                          ↓ весь исходящий трафик
┌──────────────────────────────────────────────────────────────────────────┐
│ Egress-прокси [G3] ·                                                     │
└──────────────────────────────────────────────────────────────────────────┘
                  ↓ MCP — только через Agent Runner (D19)
┌──────────────────────┐  ┌──────────────────────┐  ┌──────────────────────┐
│ ↗ LiteLLM gateway    │  │ ↗ Memory             │  │ ↗ Реестры пакетов    │
└──────────────────────┘  └──────────────────────┘  └──────────────────────┘
```

## Блоки

| Блок | Задача | Статус |
|---|---|---|
| Тёплый пул | N готовых контейнеров на профиль | ⬜ не начато |
| SandboxProvider | Docker сейчас · K8s позже | ⬜ не начато |
| /workspace | эфемерный, клон репозиториев | ⬜ не начато |
| Профиль | CPU, RAM, диск, без privileged | ⬜ не начато |
| Credential helper | токены git без env | ⬜ не начато |
| Egress-прокси | Squid: allowlist по подсети — среда агента и шаг подготовки | ⬜ не начато |

## Расширения и настройка

```
image                              → Какие инструменты доступны агенту
resources                          → Тяжёлые задачи (сборка) против стоимости
network.egress_allow               → Доступ к сервисам против риска утечки
pool.size                          → Скорость старта против постоянных ресурсов
repos.clone_depth                  → Скорость старта против доступа к истории
provider                           → Масштаб и где исполняется
runtime                            → Сила изоляции ядра против совместимости
setup.script                       → Зависимости для тестов без доступа агента к реестрам
```

## Плюсы / минусы

| ➕ | ➖ |
|---|---|
| Сбой или атака в одном запуске не задевает другие и хост | Побег из контейнера через ядро — gVisor (проверка в 2.2), rootless, без привилегий. |
| Старт за доли секунды | Пересмотр: агенты запускают код из внешних источников → microVM (Kata, Firecracker), если KVM есть. |
| Секреты не попадают к агенту |  |
