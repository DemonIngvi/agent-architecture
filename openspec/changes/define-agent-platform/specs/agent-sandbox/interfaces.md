# agent-sandbox — конфигурация, данные, интерфейсы, отказы

← [spec.md](spec.md) · [схема](architecture.md) · [трассировка](traceability.md) · [правила](../../../../../docs/rules/spec-criteria.md)

## Уровни конфигурации

| Уровень | Что | Где хранится | Область |
|---|---|---|---|
| L0 | Конфиг деплоя | S9 | платформа целиком: адреса, переключатели G1–G4, режим планирования, потолки лимитов |
| L1 | Platform module | S2 | агент: бюджеты, профили, данные guardrails, флаги планирования |
| L2 | Определение агента | S1 (+ YAML импорт) | агент: модель, инструкция, тулы, навыки, MCP, лимиты запуска |
| L3 | Запуск | задача ICPlan / `Run` | версия агента, критерии приёмки, задание |

Правило: значение берётся с самого конкретного уровня (L3 → L0), но не выше потолка L0.

### Тип `resources`

`resources` — объект профиля среды `sandbox_profile` (S2), задаётся тремя параметрами выше; значение вне Мин–Макс отклоняется с именем поля.

| Поле | Тип | Единица | Колонка `sandbox_profile` | Профиль `light` (по умолчанию) | Профиль `coder` |
|---|---|---|---|---|---|
| `cpu` | number | ядра | `cpu` | 1 | не задано спекой; в границах 0,25–4 |
| `memory_mb` | int | МБ | `memory_mb` | 1024 | 2048–6144 (профиль нагрузки: «coder» 2–6 ГБ) |
| `disk_gb` | int | ГБ | `disk_gb` | 2 | не задано спекой; в границах 1–20 |

## Нагрузка и развёртывание

| | |
|---|---|
| **Нагрузка** (гипотеза, [R&D](../../../../../docs/rnd/load-profile.md)) | до 6 контейнеров одновременно + пул 2 на профиль; обычный 0.3 ГБ / 0.2 CPU, «coder» 1–2 ГБ / 1–2 CPU |
| **Развёртывание** ([R&D](../../../../../docs/rnd/kubernetes-runtime.md)) | этапы 1–3 — Docker на узле; этап 4 — Pod на запуск в `itsaplan-agents`, NetworkPolicy только к egress-прокси; egress-прокси — Deployment 1 реплика |

Детали форматов — [потоки](../../../../../docs/how/sandbox.md).

## Отказы (FMEA)

| Отказ | Обнаружение | Поведение | Восстановление |
|---|---|---|---|
| Нет ресурсов хоста | ошибка create | запуск ждёт в `queued` | освобождение ресурсов, пул уменьшается |
| Образ недоступен | ошибка pull | профиль помечен недоступным, запуски отклоняются | восстановление реестра образов |
| Реестр пакетов недоступен на шаге подготовки | ошибка установки | шаг подготовки завершается ошибкой, запуск `failed` с причиной; при наличии кэша — используется кэш | повтор после восстановления реестра |
| Egress-прокси упал | нет соединений | исходящий трафик запрещён (fail-closed) | перезапуск прокси |
| Переполнен диск workspace | ошибка записи | запись отклоняется, агент получает ошибку | запуск завершает с частичным итогом |
| Объектное хранилище (RustFS) недоступно при подключении или выгрузке папки | ошибка S3 API (I19) | старт без папки — запуск с ошибкой «нет рабочего пространства»; выгрузка — повтор 3 раза, затем итог с пометкой «артефакты не сохранены» | повторная выгрузка из сохранённой копии до уничтожения среды |
