## Уровни конфигурации

| Уровень | Что | Где хранится | Область |
|---|---|---|---|
| L0 | Конфиг деплоя | S9 | платформа целиком: адреса, переключатели G1–G4, режим планирования, потолки лимитов |
| L1 | Platform module | S2 | агент: бюджеты, профили, данные guardrails, флаги планирования |
| L2 | Определение агента | S1 (+ YAML импорт) | агент: модель, инструкция, тулы, навыки, MCP, лимиты запуска |
| L3 | Запуск | задача ICPlan / `Run` | версия агента, критерии приёмки, задание |

Правило: значение берётся с самого конкретного уровня (L3 → L0), но не выше потолка L0.

## Параметры модуля

| Параметр | Что задаёт | Уровень | Хранилище | По умолчанию |
|---|---|---|---|---|
| `Статусы доски` | Этапы процесса | L2 | S1 | по проекту |
| `Агент-делегат статуса` | Какой агент берёт задачу в статусе | L2 | S1 | нет |
| `Агент-делегат типа` | Какой агент берёт задачу типа | L2 | S1 | нет |
| `Действия` | Условие → эффект | L2 | S1 | нет |
| `Модель агента` | Провайдер и модель (алиас) | L2 | S1 | — |
| `Инструкция агента` | Роль, правила, формат результата | L2 | S1 | — |
| `Тулы и навыки` | Что агент может делать | L2 | S1 | нет |
| `MCP проекта` | Доступ агентов к API ICPlan | L2 | S1 | выключен |
| `Тип агента` | Внутренний или внешний (наш Runner) | L2 | S1 | внутренний |

## Интерфейсы обмена

| ID | От → к | Протокол | Формат | Аутентификация | Режим | Таймаут | Повтор | Идемпотентность |
|---|---|---|---|---|---|---|---|---|
| I20 | ICPlan UI ↔ ICPlan API | HTTP REST (существующий) | JSON | сессия пользователя | синхронно | — | — | — |

## Отказы (FMEA)

| Отказ | Обнаружение | Поведение | Восстановление |
|---|---|---|---|
| Агент правила не участник проекта | проверка при срабатывании | запуск не создаётся, предупреждение в истории | администратор правит правило |
| Очередь недоступна | ошибка постановки | делегат установлен, запуск ставится повторно | повтор постановки |
| Цикл переходов статусов | повторы одного правила по задаче | защита от дублей + лимит запусков на задачу | правка процесса |
