## Why

В ICPlan агент запускается только при смене поля «Делегат» или упоминании. Автоназначение на статус заполняет только «Исполнителя» и запуск не создаёт (проверено: `issues/service.ts`, `enqueueDelegateRun`). Поэтому процесс «задача пришла в статус / создана с типом → агент сам подхватил» не работает. Процесс (статусы, типы, порядок) пользователь настраивает в ICPlan сам; ICPlan должен уметь автоматически отдавать задачу указанному агенту.

## What Changes

- Агент-делегат по умолчанию для статуса (колонки).
- Агент-делегат по умолчанию для типа задачи.
- Эффект Действия «делегировать агенту».
- Защита от дублей запуска и понятный приоритет правил.
- Передача между этапами: следующий агент получает ссылки на результаты предыдущего.
- Видимость автоподхвата в истории задачи.

Изменения только в ICPlan. Сроки — при планировании.

## Impact

- Форк `itsaplan`: модули `columns`, `issue-types`, `actions`, `issues`, `agents/core`; UI настроек статусов, типов и действий.
- Не затрагивает процесс пользователя: какие статусы и агенты — решает пользователь.
