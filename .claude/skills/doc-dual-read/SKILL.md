# Проверка двумя читателями

Правило — `docs/rules/dual-read.md`.

1. Собрать сайт: `python html-view/build.py`.
2. Снимок для читателей (без доступа к исходникам): из `html-view/.build/docs/data-model.md` — раздел от `## Контракты обмена` до `## Все поля`; из `html-view/.build/docs/docs/flows/data-types.md` — от `## Типы` до конца. Сохранить в папку scratchpad.
3. Запустить **двух** агентов независимо, одинаковым заданием: читать только эти два файла; на каждую модель — что это, кто → кому, почему такая структура, почему такие имена, неясные поля, противоречия; на каждый I-код — кто вызывает кого, что туда и обратно, зачем; общие неясности. «Чего нет — пиши «в тексте нет», не додумывай».
4. Сравнить по смыслу: совпало · разошлось · совпало, но не так · непонятно. Всё, кроме «совпало», исправить **в источнике** (`datamodel.py`, каталог API, design) — решения только из существующих D / R, иначе вопрос в `open-questions.md` спеки.
5. Повторять, пока объяснения не совпадут по смыслу. Протокол — `docs/reviews/<дата>-dual-read.md`.
