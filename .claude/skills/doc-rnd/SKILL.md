# Новое R&D

1. Заготовка: `python html-view/doctool.py rnd <slug> <тема>` — файл `docs/rnd/<slug>.md` со структурой v3.1 (Э1–Э10, ворота G1–G10, первая страница).
2. Строка в реестре `docs/rnd/README.md` (последняя колонка — `v3.1`).
3. Этапы — по `docs/rules/rnd-methodology.md`: открывать раздел нужного этапа, а не весь файл. Факты — с источником и датой; код форка и OpenAPI ICPlan — уровень А.
4. Э10 «Последствия»: каждая строка — документ и статус ✅ / 📌; внести решение в `openspec/changes/<change>/design.md` и все последствия (спеки, `html-view/datamodel.py`, API, потоки, задачи).
5. Проверка: `python html-view/doctool.py check` (структура v3), затем сборка.
