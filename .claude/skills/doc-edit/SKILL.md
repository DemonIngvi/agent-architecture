# Правка документа

Правила не пересказываются здесь — их выжимку по конкретному файлу даёт инструмент.

1. **Тип и правила файла:** `python html-view/doctool.py route <файл>` — тип, что обязательно, чего нельзя, источник, методология, что синхронизировать.
2. **Генерируемый файл?** `python html-view/doctool.py generated <файл>` — если да, правь источник (хук до правки всё равно остановит).
3. **Факт живёт в одном месте:** перед тем как писать значение, поле, конфиг или список — найди источник (`docs/rules/change-process.md#single-source`) и поставь ссылку.
4. **Правка.** Многострочные замены — через инструмент Edit или скрипт, записанный в файл; не через heredoc с обратными слешами (О-14).
5. **Проверка:** `python html-view/doctool.py check` (секунды); перед коммитом — `python html-view/build.py` и `openspec validate <change> --strict`.
6. **Нашёл расхождение** — строка в `docs/rules/deviations.md`: что → почему → правило и проверка.
7. Модели, интеграции, имена — навык `doc-dual-read`; данные — `doc-data`; новое исследование — `doc-rnd`.

Подробности, если выжимки мало: `docs/rules/doc-work.md` (по типам), `docs/rules/doc-types.md#tabs` (вкладки).
